⚡ LiteCode 使用说明

LiteCode 是跑在你自己电脑上的 AI 员工：会用工具、记得你、能自己拆任务干活。桌面版只对本机开放，数据不出这台电脑。

1. 打开与登录

双击桌面或开始菜单里的 LiteCode。首次启动约 30 秒，就绪后会自动弹出 LiteCode 窗口。

默认登录密码：admin

请登录后尽快在 设置 → 修改密码 改掉默认密码（新密码至少 6 位）。

2. 配置模型

LiteCode 需要一个 OpenAI 兼容 的模型接口（DeepSeek、通义、Kimi、自建 vLLM / Ollama 都行）。

打开 设置，在「ADD NEW MODEL」里填：接口地址（例如 https://api.deepseek.com/v1）、模型名、API Key，保存后点「🔍 测试」确认能用，再点「切换」。

对话中也能临时换模型：输入框下方的「模型」按钮，或发送 /model 模型名。

3. 日常使用

发消息输入框回车。任务进行中也能继续打字：回车是补充（当前这一步做完看到），点「⚡ 立即」是打断并调整。
停止顶部「⏹ 停止」，1 秒内生效。
录屏「⏺ 录屏」：这个对话每一轮自动录成 mp4，结束后在回复里播放、下载。「🎥」：手动录当前窗口。
文件回形针上传；LiteCode 生成的文件会在回复里出现预览卡片，可直接看、可下载。
分享顶部「🔗 分享」生成只读链接（仅本机可访问的地址，适合局域网内演示）。
记忆 / 定时任务 / 流水线左侧栏对应入口；说「每天 9 点帮我……」它会自己建定时任务。

4. 操控本机

LiteCode 就运行在这台电脑上，可以直接帮你干活：

· 生成文件：说「做一页 PDF 放到我的文档」「在桌面建个表格」，文件直接出现在 桌面 / 文档 / 下载，回复里给出完整路径。

· 执行命令、打开程序：「打开我的下载文件夹」「看看 C 盘还剩多少空间」——优先用命令行完成，快且稳。

· 看屏幕、点鼠标：「截一张本机屏幕看看」「帮我在某个软件里点一下」——只有必须看界面时才用。需要已接入本机操控（安装时默认接入）。

接入：安装最后会请求一次管理员权限，安装 OpenSSH Server（开机自启，只允许本机/局域网、只认密钥不认密码）和 LiteCode 桌面代理（你登录后在桌面运行，用于截图和点击）。当时点了「否」或没装上，可随时在托盘菜单点「接入本机操控 / 重新接入本机操控」。

关掉：卸载 LiteCode 会移除桌面代理；也可在 LiteCode「Windows 节点」里撤销 this-pc。不需要 SSH 时，在管理员 PowerShell 运行 Stop-Service sshd; Set-Service sshd -StartupType Disabled，或到「设置 → 系统 → 可选功能」卸载 OpenSSH 服务器。

安全：LiteCode 操控本机的权限就是你当前 Windows 账户的权限，请只让它做你本来就允许自己做的事；重要文件先备份。不放心时可以在托盘「停止服务」，或按上面的方法关掉。

5. 托盘菜单（右下角橙色闪电图标）

打开 LiteCode打开窗口（没就绪会先提示“正在启动”）。
启动 / 停止服务停止后 LiteCode 不占内存；再点启动约 30 秒恢复。
检查更新有新版会提示，确认后约 1 分钟更新完，对话和设置都保留；新版起不来会自动回滚。
查看日志出问题时把这份日志发给维护人员。
打开数据文件夹%LOCALAPPDATA%\LiteCode。
接入本机操控安装 / 修复 OpenSSH 与桌面代理（需要管理员确认，约 2~5 分钟）；已接入时显示为「重新接入本机操控」。
退出只退出托盘，服务保持运行；开机会自动启动。

图标看不到时，点任务栏右下角的 ^，可以把它拖到任务栏上常驻。

6. 常见问题

窗口一片空白：服务还没起来。稍等片刻按 F5 刷新，或从托盘「打开 LiteCode」。
安装时提示要重启：电脑第一次开启 WSL 需要重启一次，重启后会自动接着装；只会发生一次。
提示“WSL 仍然不可用”：通常是 BIOS 没开虚拟化，或虚拟机没开嵌套虚拟化。在管理员 PowerShell 运行 wsl --status 查看原因。
连不上服务器 / 下载失败：检查是否开着失效的系统代理（例如代理软件已退出但还设着 127.0.0.1:7890）：设置 → 网络和 Internet → 代理，关掉“使用代理服务器”。
模型报错 401：API Key 不对或过期。到设置里改 Key 后点「🔍 测试」。

7. 卸载

Windows「设置 → 应用 → 已安装的应用」找到 LiteCode 卸载，会一并删除 LiteCode 子系统和数据。卸载前需要保留的对话请先导出。
