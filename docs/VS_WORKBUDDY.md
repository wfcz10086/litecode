# LiteCode vs 腾讯 WorkBuddy 功能对比

> 整理日期 2026-10-21。WorkBuddy 资料来自官网、更新日志和媒体评测，每条附来源；LiteCode 一侧以本仓库代码为准（工具定义 `litecodeext/lib/tools/defs/*.py` + `plugins/tools/*.py`，技能 `litecodeext/skills/`）。
> WorkBuddy 更新日志页经摘要读取，个别功能的版本号前后对不上（例如 computer-use 记成 4.22.4 或 5.1.1），版本号只作参考，日期比较可靠。

## 一、WorkBuddy 是什么

| 项目 | 内容 |
|---|---|
| 出品 | 腾讯云 CSIG。和 AI 编程助手 CodeBuddy 共用底座，吸收了 QClaw 的能力；媒体称"腾讯版 OpenClaw / 龙虾"，官方说"100% 自研" |
| 发布 | 2026-03-09 正式公测（4.5.0 版本日期为 03-04） |
| 最新版本 | 5.8.3（2026-10-19） |
| 平台 | 桌面 Windows / macOS / 统信 / 麒麟；手机 App 2026-07-18 起支持 Android / iOS / 鸿蒙；另有网页端、企业微信小程序；海外版 workbuddy.ai |
| 模型 | 混元、DeepSeek V4、GLM 5.3、Kimi K2.6、MiniMax，也可接自定义模型；免费版只能用"自动调度"，Pro 版可以自选 |
| 定价 | 积分制。国际版：Free 每月 100 积分；Pro $10/月，每月 2000 积分；Team $40/席/月。国内版：标准版约 ¥70–99/月，2000 积分。企业版 4 月下旬调价：SaaS 从 ¥78 调到 ¥198/人/月 |
| 规模 | 上线 3 个月 DAU 超 1300 万（PC 端超 200 万），付费席位超 10 万 |

主要来源：[腾讯云产品页](https://cloud.tencent.com/product/workbuddy) · [官方文档 Overview](https://www.codebuddy.cn/docs/workbuddy/Overview) · [更新日志](https://www.codebuddy.cn/docs/workbuddy/Changelog) · [订阅说明](https://www.workbuddy.ai/docs/zh/workbuddy/Subscription) · [TechNode 发布报道](https://technode.com/2026/03/09/tencent-launches-openclaw-like-workplace-ai-agent-workbuddy/) · [爱范儿专访](https://www.ifanr.com/1658088) · [IT 之家（移动端）](https://www.ithome.com/0/978/468.htm) · [老虎证券资讯（数据与调价）](https://www.itiger.com/hans/news/2654008710)

用户吐槽最多的几点：
- 积分消耗快，扣分规则不透明，失败的任务也扣分（[什么值得买](https://post.smzdm.com/p/a4qx4g3w/)、雪球、头条）。
- 任务做到一半就停下来等"继续"。
- 电脑关机后定时任务不跑。
- 云端虚拟机启动慢，最近几个版本有报错、卡死。
- 第三方 70 项测评平均 2.31/4。
- 视频能力弱：不能原生解析抖音、B 站链接（[BibiGPT 评测](https://bibigpt.co/zh/blog/posts/workbuddy-expert-team-watch-douyin)）。
- computer-use 只支持 macOS，而且是实验功能。

| 3D、品牌设计 | 有 | canvas-design / theme-factory 能做平面设计；没有 3D | 弱 | 不急 |

视频合成、时间线（第 5 节）的具体能力：
- 一条命令合成成片：配音、SRT 字幕和烧录字幕、图片或视频画面、BGM。
- 每段时长取配音实测值，并对齐到整帧。
- 视频固定 30fps，音频统一 48k。
- 字幕时间取实测的人声起止。
- BGM 在人声出现时自动压低，结尾淡出对齐片尾。
- 合成后自动校验，不过就报错：音画时长差 ≤1 帧，字幕与人声误差 ≤100ms，段落边界逐样本一致。

## 三、结论

**我们明显强的地方**（对外宣传就讲这几条）：
1. **私有化，零积分**：自托管，接任意模型，没有积分焦虑。积分正是 WorkBuddy 被吐槽最多的地方。
2. **常驻服务器**：定时任务关机照跑；任务自托管到完成，不会半路停下等"继续"。
3. **Windows 真机操控 + 服务器运维**：WorkBuddy 的 computer-use 只支持 macOS 且仍是实验功能，也没有 SSH 运维。
4. **DAG 流水线**和**四层记忆**。
5. **音视频一条龙**（本次补齐）：抖音解析、无水印下载、文案解读、配音、时间线对齐成片、配乐都是原生能力；WorkBuddy 这些都要靠第三方技能。

**我们落后的地方**：
1. **触达渠道**：没有手机 App，没有 QQ、钉钉、飞书。
2. **生态**：没有技能在线市场，没有专家中心，MCP 面板偏弱。
3. **体验层**：没有文件浏览器内的在线编辑，没有资料库面板，Web 端没有语音输入。
4. **创意生成**：没有文生视频，图片处理没有成套技能，没有 3D。
5. **团队协作**：定位不同，暂不追。

**补齐优先级**（按投入产出排）：

| 优先级 | 事项 | 理由 |
|---|---|---|
| P0 | 飞书、钉钉机器人；手机端 PWA | 手机遥控电脑是 WorkBuddy 的主卖点，我们已有微信和企微，补两个渠道成本低 |
| P0 | 专家卡片：把人格技能、行业技能包装成可选"专家"，并给专家团预设（文案 + 剪辑 + 审核） | 纯包装，复用现有技能和 spawn_agent |
| P1 | 技能导入：兼容 OpenClaw/Claude 技能格式，导入时做安全扫描 | 直接借用对方生态 |
| P1 | image-edit 技能：抠图、超分、老照片修复、AI 去水印修复 | 补齐图片处理，也让去水印效果更好 |
| P1 | Web 端语音输入 | ASR 通道已有（qwen3-asr-flash），只差前端 |
| P2 | 文生视频插件（可灵、即梦，配了 key 才启用）；MiniMax 作曲配 key | 插件骨架现成 |
| P2 | 资料库面板、MCP 面板 | 体验补齐 |
| P3 | 团队协作、3D | 和定位不符，观望 |

## 实测跑分 (2026-10-21)

22 题办公任务集 (Word / Excel / PPT / 调研 / 数据分析 / 文件整理 / PDF / OCR / 多图对比 / 抖音 / 代码 / 定时任务 / 长文 / 翻译 / 操控 Windows / 格式转换), 每题用脚本自动判分 (能否打开、公式重算、标准答案比对、隐藏单测、读回文件), 质量类题目由另一模型按固定细则打分。主模型为自建 GLM-5.3-Flash。

| | 题数 | 全部通过 | 平均分 | 中位耗时 |
|---|---|---|---|---|
| 服务器版 第 1 轮 | 22 | 20 | 95.5 | 27.9 s |
| 服务器版 第 2 轮 (复测) | 20 | 20 | 100 | 24.4 s |
| Windows 桌面版 (子集) | 10 | 10 | 100 | 17.6 s |

- 第 1 轮未过的两题: 抖音解读 (当时尚无抖音能力, 合入 douyin-toolkit 后通过)、记事本操控 (节点被并行任务占用后中途收尾; 重试完成但漏了关闭窗口)。
- WorkBuddy 需要微信 / QQ / 手机号扫码登录并按积分计费, 无法自动化实测, 因此只按公开资料逐类对照, 不给它打分。
- 跑分发现的待办: 回合在"宣称下一步"后提前收尾 (P0)、GUI 任务收尾逐条核对 (P0)、节点忙时排队 (P1)、子代理视觉自检走识图回退 (P1)、每次调用约 5 万 token 固定前缀需压缩 (P2)、任务集需要更难一档以恢复区分度 (P2)。
