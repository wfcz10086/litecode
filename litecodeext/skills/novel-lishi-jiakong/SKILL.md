# 历史架空写作规范

## 与 novel-lishi (正统历史) 的区别
| 维度 | lishi (正统) | lishi-jiakong (架空) |
|---|---|---|
| 史实红线 | 不能改变重大结局 | 可以自由虚构 |
| 人物 | 必须真实 | 可用原型但改名 |
| 朝代 | 必须真实 | 可虚构, 但要像某朝代 |
| 参考查证 | 严格 | 风貌准即可 |
| 难度 | 史实考据 | 世界观建构 |

## 核心技法: "朝代气质借鉴"

虽然架空, 但不能乱写 — 读者需要"代入感":

```
借唐: 繁华 / 开放 / 诗歌 / 胡风 / 长安 → 虚构"大周" / "大齐" / "离国"
借宋: 雅致 / 文官政治 / 商业 / 词 → 虚构"大梁" / "景朝"
借明: 内敛 / 党争 / 锦衣卫 → 虚构"启朝" / "靖朝"
借清: 严整 / 满汉 / 科举 → 虚构"晟朝" / "永朝"
借民国: 新旧交替 / 军阀 / 留学 → 虚构"共和"
```

选定后全书气质一致 — 不能混搭 (除非明确"几百年后融合")。

## 世界观必备字段 (比正统历史更需要)
```yaml
dynasty_name:    # 虚构朝代名 (2 个字, 像真实朝代)
founding_year:   # 建朝年 (本朝纪元)
current_year:    # 故事发生年 (本朝第 X 年)
reference_era:   # 参考真实朝代 (只内部用, 不写进正文)
geography:       # 疆域 / 首都 / 重要城市 (地图简图)
political:       # 政治体制 (文官/武将/宦官/外戚势力平衡)
military:        # 军制 (府兵/募兵/卫所)
economy:         # 经济 (农业为主 + 商业 + 海贸?)
religion:        # 信仰 (自创宗教 / 儒释道变体)
fantasy_element: # 超自然 (0 = 纯架空; 1 = 有气运/风水; 2 = 有修仙/妖怪)
```

## 常见爽点
- 预知危机 (主角知道"XX 将乱"提前布局)
- 改良技术 (造纸 / 火药 / 曲辕犁)
- 科举跃迁 (从贫寒到状元)
- 边疆立功
- 朝堂权谋
- 革新法制

## 常见坑 (实测读者最烦)
- ❌ **开局万字塞世界观**: 读者要看故事不是看设定书
- ❌ **主角朝堂论道直接成功**: 政治博弈要反复交锋
- ❌ **金手指直通皇帝**: 从平民到皇帝亲信要有足够台阶
- ❌ **虚构朝代完全 1:1 复刻真朝**: 不如直接写正统历史
- ❌ **架空却用真朝代人名** (魏征 / 诸葛亮 出现在架空 = 穿帮)
- ❌ **主角现代词汇漏出**: "项目/KPI/效率" 要全文滤掉
- ❌ **女性人设全现代三观** (失去时代感)
- ❌ **战争只写数字** (十万 vs 二十万), 不写兵种 / 地形 / 补给

## 章节结构
```
3000 字:
  场景 / 氛围 (500)
  政治 / 战事推进 (1200)
  主角应对 (800)
  余韵 / 钩子 (500)
```
