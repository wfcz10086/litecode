# 种田题材写作规范

## 核心气质 (独特)
- **节奏慢, 日常化** (不追爽点, 追"踏实感")
- **数字实在** (一亩地产多少斤 / 一两银子买什么)
- **人际真实** (家人 / 邻里 / 村里关系)
- **成长可见**: 从一穷二白 → 吃穿不愁 → 家业兴旺

## 典型子类型

### A. 古代种田 (最主流)
- 穿越到古代农村 / 山民 / 渔村
- 靠现代知识 (种子嫁接 / 酿酒 / 养殖) 发家
- 金手指: 空间 / 种子 / 异能 (节制使用)

### B. 末世种田
- 末世背景下的"基地农业"
- 异能灌溉 / 变异作物 / 稀缺资源
- 节奏慢但危机感强

### C. 现代种田
- 回农村 / 开民宿 / 做农家乐
- 短视频 / 直播带货 现代元素
- 金手指: 灵泉 / 异能 / 系统

### D. 基建
- 荒野拓荒 / 异世界建城
- 从 0 到 1 建立社区
- 数字党的最爱 (人口 / 粮食 / 经济)

## 爽点 (慢品而非速爽)
- 第一次赚到钱 (0 → 1, 最激动)
- 盖新房 / 买地 / 娶嫁
- 吃美食 (写吃是本题材灵魂)
- 冬天囤粮充足
- 孩子出生 / 成才

## 数字必须扎实
```
一亩上田  年产   200-300 斤 (古代水稻)
一亩中田          150-200 斤
一亩下田          80-120  斤
一文钱  = 1/1000 两银子
一两银子 ≈ 300-500 元 (明清换算)
一斤肉   ≈ 20-30 文
```
不要瞎编数字 — 写前搜"X 朝 Y 物 价格"

## 描写要点 — 五感吃饭场景
```
✅ 好: "锅里的大骨汤咕嘟咕嘟冒着泡, 香味飘出院子, 二狗子咽了咽口水.
       她掀开锅盖, 白雾升腾, 能看见萝卜炖得透亮, 大块骨头上的肉都煮脱了."
```

## 人物配置
- 主角: 穿越者 / 重生农妇 / 寒门子弟
- 家人: 多重要 — 父母 / 兄嫂 / 子女 (种田主要写"过日子")
- 反派: 恶邻 / 极品亲戚 / 贪官 / 山匪 (小格局, 不搞大 Boss)
- 贵人: 遇到 1-2 位有远见的"伯乐" (推主角发家)

## 结构模板 (慢节奏章节)
```
3000 字 / 章:
日常铺垫 (1200): 天气 / 饭食 / 家常
行动 (1000):    下地 / 赚钱 / 议事
小冲突 (500):   邻里 / 家人 / 偶发
收尾 (300):     温情 / 下步规划
```

## 套话黑名单
- "在古代当咸鱼"
- "老天爷赏饭吃"
- "日出而作日落而息"
- "小富即安"
- "家和万事兴"
- "远亲不如近邻" (用多就假)

## 禁忌
- ❌ 直接暴富 (违反种田精神, 读者要看"慢慢来")
- ❌ 反派过强 (种田格局不大, 反派要合情理)
- ❌ 忽略女性劳动 (古代种田家务 = 女性主导, 不能只写男主角农活)
- ❌ 一章盖大宅 (进度快, 没沉浸感)
- ❌ 空间无限大 (要有限制 / 代价)
