# 修真题材写作规范

## 核心爽点
- 追求"长生"与"大道" (比玄幻更"仙气")
- 师门传承 + 历劫飞升 + 登顶三十三天
- 每次突破大境界必有天劫描写 (雷劫/心魔劫)

## 标准境界体系 (不要乱改)
```
练气期 (1-9层) → 筑基期 → 金丹期 → 元婴期 → 化神期 → 炼虚期 → 合体期 → 大乘期 → 渡劫期 → 飞升
```
- 练气 9 层内无天劫
- 筑基必有"筑基雷劫" (小劫)
- 金丹分"九品莲花", 品阶决定后续上限
- 元婴能出窍、分神
- 化神起不吃凡间食物
- 渡劫每次必写: 雷劫 + 心魔劫 + 风劫 (可自选 3-9 道)

## 功法分类
```
功法: 修炼根本 (决定境界增长)
心法: 调心入静 (配合功法)
剑法 / 掌法 / 身法: 战斗辅助
神通: 元婴期后解锁
秘术: 特殊来源, 代价大
```

## 人物配置
- 主角: 散修 / 世家 / 宗门外门弟子, 资质差但有奇遇
- 师父: 1 位真正传功的师父 (情感核心, 通常在中期去世推高潮)
- 道侣: 1-2 位 (不要像玄幻那样后宫)
- 反派: 同门师兄 → 邻宗门长老 → 魔道巨擘 → 天外大能

## 金手指
- ✅ 系统 / 老爷爷戒指 (给功法不给境界)
- ✅ 先天灵根 / 天生道体 / 万载灵根
- ✅ 穿越带前世记忆 (要合理, 不能啥都知道)
- ❌ "加速修炼"不能太离谱 (凡人修仙本身慢节奏)

## 必守节奏 (相对玄幻更慢)
- 练气期 30-50 章 (世俗戏份多)
- 筑基期 40-60 章 (入宗门 / 筑基丹争夺)
- 金丹期 60-80 章 (门派纷争 / 历练秘境)
- 元婴+ 后期爆发, 每境界 50+ 章

## 套话黑名单
- "大道三千, 殊途同归"
- "天地不仁, 以万物为刍狗"
- "此乃吾辈修仙之不二法门"
- "师祖留下一线生机"
- "你等凡夫俗子"
- "我辈修仙为求长生"
> 可以用 1-2 次 (营造古风), 但不能段段都来。

## 章节模板 (每章 3000 字)
开场(场景/状态) → 修炼/历练(1500) → 遭遇/冲突(800) → 提升/领悟(500) → 钩子(200)

## 世界观字段
```yaml
realms:          # 位面
  - 凡间 → 小界 → 中界 → 上界 → 仙界 → 混沌
qi_sources:      # 灵气来源 (决定修炼速度)
  - 灵脉 / 阵法 / 灵石 / 天地灵气
sects:           # 门派
  - 正道四大派 + 魔道三大殿 + 散修联盟
forbidden_zones: # 秘境 / 绝地
laws:            # 天道规则 (渡劫必独自; 因果不可违)
```

## 禁忌
- ❌ 穿越者用现代思维嘲笑古人 (破坏沉浸)
- ❌ 修为随便泄露 (低调是修真人设关键)
- ❌ 女主全是"冷艳倾城仙姿" (至少一位平凡)
- ❌ 渡劫秒过 (必须惨烈, 否则读者无感)
- ❌ 滥用"功德"来解释金手指
