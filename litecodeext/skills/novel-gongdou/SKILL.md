# 宫斗 / 权谋写作规范

## 核心
- **智斗 > 打斗**: 靠 "算计 / 布局 / 伏笔" 而非武力
- **人心刻画**: 每个角色都有"动机层次"(表面/深层/秘密)
- **隐忍 + 爆发**: 主角前期受气, 积蓄力量, 后期反击
- **伏笔密度高**: 一句闲话可能 20 章后成为关键

## 常见子类型
- **后宫宫斗**: 皇帝 + 妃嫔们. 以皇宠 / 生育 / 家族后台为筹码
- **大家族宅斗**: 嫡 vs 庶 / 正妻 vs 妾 / 姑嫂斗
- **朝堂权谋**: 文官党争 / 外戚 / 宦官 / 皇子夺嫡
- **女官斗**: 女主入朝, 如《女医·明妃传》

## 必守"规矩" (古代真实氛围)
- 等级森严: 妃嫔 / 主子 / 奴婢, 规矩必须守
- 称谓准确: 皇后/皇贵妃/贵妃/妃/嫔/贵人/常在/答应
- 礼仪细节: 请安 / 行礼 / 避讳 / 忌讳不能乱
- "不好的死法": 冷宫 / 赐死 / 流放 / 绞杀

## 人物配置
- 主角: 聪敏隐忍, 起点低 (秀女 / 庶女 / 小官女儿)
- 皇帝 / 家主: 多疑 / 玩弄权术 / 有软肋
- 竞争对手: 2-3 位 (阶段性 Boss, 一卷一个)
- 盟友 / 背叛者: 关键转折点
- 老谋深算者: 太后 / 老夫人 (背后真正推手)

## 节奏
```
前 10 章: 立人设 + 小受挫 + 伸手援手出现
中卷: 第一次反击 + 阶段性胜利 + 更强敌人现身
后半段: 连续政治操作 + 大反转 + 反派倒台
收尾: 主角位居高位, 或看破归隐
```

## 爽点 (女频特色)
- 一句话反杀 (留白够, 读者细品)
- 被误会清白 → 反转澄清 → 恶人现原形
- 表面顺从实则 步步为营
- 旧情人 / 真爱人 的情感呼应

## 常见坑
- ❌ **智斗变嘴硬**: 不能靠"你敢?"就赢, 要真行动
- ❌ **主角开金手指秒杀**: 没有博弈感
- ❌ **反派脸谱化**: "恶毒女配" 一眼坏到底 → 太假
- ❌ **男主超级完美**: 现代言情病, 宫斗男主要有政治污点
- ❌ **伏笔断线**: 前面埋的后面忘记兑现
- ❌ **现代思维代入**: "我不嫁人也能独立" 在古代语境违和
- ❌ **对话全是阴阳怪气**: 要有正常对话与尖锐对话交错

## 描写要点 — "话中有话"
```
✅ 好:
"妹妹今日穿的石榴裙, 可是去年皇贵妃赏的那件? 真是······" 她笑着没说完,
端起茶盏.

(潜台词: 妹妹你居然还敢穿皇贵妃的旧赏赐, 是想攀关系?)

❌ 烂: 
"你怎么穿着这衣服? 你是不是想巴结皇贵妃?" 她愤怒地说道.
```
