# 末世题材写作规范

## 核心
- **资源 + 人性** 是永恒主题, 不是"打丧尸升级"
- 真正的反派常常是人, 不是怪物
- **基地 / 避难所** 是本题材的"宗门 / 家族"

## 常见子类型

### A. 丧尸末世
- 标配: 丧尸 + 变异动物 + 幸存者派系
- 金手指: 异能觉醒 / 空间戒指 / 前世记忆
- 典型节奏: 被围困 → 逃生 → 找基地 → 发展势力 → 远征

### B. 废土 (辐射 / 核战后)
- 沙漠化场景 + 突变生物 + 残存科技
- 主角常是"修修补补"的幸存者
- 《辐射》系列气质

### C. 异次元入侵
- 空间裂缝 / 虫洞 / 次元怪物
- 人类科技 vs 异能力
- 末日来得突然, 人类措手不及

### D. 天灾末世
- 洪水 / 地震 / 火山 / 冰河 / 外星撞击
- 不一定有"敌人", 主要对抗自然
- 氛围偏灰暗, 少打斗多生存

## 物资体系 (本题材的"境界")
```
末世前资源 > 初期囤积物 > 幸存者交易品 > 稀缺战略物资

分级 (示例):
D 级: 粮食 / 水 / 火种
C 级: 弹药 / 药品 / 燃料
B 级: 发电机 / 电台 / 武器
A 级: 异能晶核 / 远程通讯 / 军用级
S 级: 疫苗 / 能源堆 / 空间装备
```
- 具体等级可换皮, 但**分级必须清晰**
- 每次得到新级别物资是小爽点

## 人物配置
- 主角: 必须有一个"末世前身份" (医生 / 军人 / 程序员), 影响末世战略
- 核心团队 3-5 人: 战斗 / 辅助 / 情报 / 医疗 / 后勤
- 反派势力: 邪教 / 军阀 / 实验室 / 异能猎人
- 红颜: 1-3 位, 末世背景下的情感要有"活下去"的紧迫感

## 爽点密度
- 每 2000 字一个小爽点 (击败一群丧尸 / 找到物资 / 救出同伴)
- 每 8-10 章一个大事件 (基地围城 / 远征 / 发现真相)
- 每章开头暗示当天危险, 结尾有阶段性胜利或新危机

## 套话黑名单
- "丧尸潮"(用了无数次, 建议换"浪潮/狂潮/洪流")
- "世道变了"
- "末世法则"
- "人不如狗"
- "大事不妙"
- "杀丧尸就像割草"
- "变异生物"(太宽泛, 要写具体)

## 描写要点
- **气味和痛感**: 末世气氛靠感官堆叠 (腐臭 / 血腥 / 饥饿感)
- **细节现实**: 多久洗澡 / 弹药怎么分配 / 汽油从哪里来
- **人性暗面**: 不能全是好人, 必须有"为了活下去" 做恶的灰色角色

## 世界观字段
```yaml
catastrophe:    # 灾难类型 + 时间线
  - 起因 / 爆发日 / 当前 Day X
threat:         # 主要威胁
  - 丧尸种类 / 变异生物 / 辐射 / 极端气候
resources:      # 资源分级体系
factions:       # 势力
  - 政府残余 / 军方 / 邪教 / 企业 / 幸存者联盟
locations:      # 重要地点 (大城市 / 军事基地 / 研究所)
technology:     # 末世后科技水平 (电力能用? 互联网? 无线电?)
```

## 禁忌
- ❌ 不断发现新"觉醒者" (稀释主角金手指)
- ❌ 物资过剩 (末世就是缺, 不能天天吃肉)
- ❌ 丧尸智商变化 (开始普通, 后来会说话 — 除非早期铺垫)
- ❌ 女性角色只负责哭 / 做饭 (要有行动力)
- ❌ 结尾"世界恢复正常" (末世作品通常不圆满)
