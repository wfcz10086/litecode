# 悬疑推理写作规范

## 核心黄金圈
- **公平竞赛**: 所有线索读者都能看到 (不在最后一章才出新证据)
- **诡计可逆**: 从真相倒推能还原作案过程
- **动机合理**: 凶手的逻辑能理解 (即便变态也有内在自洽)
- **不用超自然解释**: 除非本来就是恐怖/灵异

## 子类型
- **本格推理**: 诡计第一, 侧重"如何杀 + 不在场证明"
  - 密室 / 暴风雪山庄 / 时刻表诡计
- **社会派**: 动机第一, 凶手的人性扭曲是卖点
  - 复仇 / 阶级矛盾 / 家庭伦理
- **硬汉派**: 侦探自己冒险, 多动作少纯推理
- **日常推理**: 无命案, 解谜日常怪事 (《冰菓》)
- **悬疑惊悚**: 重气氛, 不一定有明确凶手
- **法医 / 警察程序**: 《法医秦明》风格, 专业细节

## 章节结构 (最讲究)
```
Day 1 案发章: 尸体/案情 + 侦探登场 + 嫌疑人初印象
Day 2 勘察章: 现场细节 + 物证 (都藏线索)
Day 3 盘问章: 嫌疑人逐一对话 (每个都有可疑点和证词矛盾)
Day 4 推理章: 侦探提出假设, 进一步调查
Day 5 反转章: 假设被推翻, 新证据出现
Day 6 再推理章: 新假设
...
Day X 揭晓章: 侦探集合所有人, 抖包袱 (这一章是爆点)
Day X+1 收尾章: 动机解释 / 情感落点 / 案后反思
```

## 爽点密度
**悬疑的爽 = 读者智力参与感**
- 每 2000 字给一条线索 (可能是伏笔, 可能是误导)
- 每 5000 字让读者有一次"诶? 是不是 X?"的猜测
- 每 10000 字抛一次反转
- 揭晓章前 3 章达到"欲罢不能"密度

## 写法要诀

### 线索对称 (黄金规则)
```
真相: 凶手利用潮汐时间作案, 伪造不在场证明
  → 前文必须提过:
    - 海边 / 潮汐 / 时刻表 (至少 3 次 "无关" 提及)
    - 凶手懂海洋知识 (一次含糊暗示即可)
    - 案发时间与潮汐关系 (可由侦探现场发现)

不公平: 凶手有"绝技"未曾提过, 揭晓时才说
  → 读者会觉得被骗
```

### 红鲱鱼 (误导手法)
- 故意让无辜者看起来可疑
- 但必须"合理": 无辜者有合理理由看起来可疑, 不是作者瞎塞
- 最终澄清时要让读者"原来是这样"而不是"啊?"

### 证词矛盾法
每个嫌疑人的证词互相对照, 矛盾处就是线索:
```
A 说 "晚 8 点听到楼上砸东西"
B 说 "晚 8 点我在楼上看电视"
→ 两人至少一个说谎
```

## 人物配置
- **侦探**: 有独特视角 (逻辑派 / 直觉派 / 社会学派)
- **助手**: 代读者发问 (华生式)
- **凶手**: 不能一眼就看出, 但复盘时所有细节成立
- **受害者**: 要让读者关心 (若读者不关心, 破案就没意义)
- **红鲱鱼**: 1-3 位"误以为是凶手"的角色

## 常见坑 (本题材最多)
- ❌ **最后才出新线索**: 最忌讳, 算作弊
- ❌ **凶手是"第一次出场的人"**: 读者没代入感
- ❌ **凶手是主角**: 除非从头就是叙述者诡计 (要有铺垫)
- ❌ **动机牵强**: "因为她瞪了我一眼就杀了她" — 假
- ❌ **科学错误**: 血迹形态 / 尸僵 / DNA 不懂就查
- ❌ **侦探过于聪明**: 5 分钟破案, 没有挣扎就没张力
- ❌ **证词前后矛盾自己没圆**: 作者也没想清
- ❌ **一章内多个案件平行**: 读者跟不上
- ❌ **结尾凶手长篇自白**: 让他在被捕前"抒情"很假

## ⚠️ 强制搜索
- 刑侦 / 法医 / 毒物知识 → 必搜 (不能编)
- 法律条文 → 必搜
- 专业手段 (指纹 / DNA / 弹道 / 尸检)
- 城市地标 / 交通 (现代悬疑)
- 历史悬疑要搜朝代细节

## 套话黑名单
- "完美犯罪"  (真有就不会被破)
- "真相永远只有一个"  (柯南台词, 照抄没味)
- "凶手就是你"
- "我等你很久了"
- "一切尽在掌握"
- "没有任何破绽"  (说了就是有破绽)
