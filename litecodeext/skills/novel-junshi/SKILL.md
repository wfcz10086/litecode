# 军事 / 战争题材规范

## 核心
- **战术真**: 不能写"一万人突进" — 必须有阵型 / 侧翼 / 后勤
- **兵种详**: 古代骑兵/步兵/弓兵/辎重; 现代坦克/步兵/空军/海军
- **不避残酷**: 战争是死亡机器, 不能只写英雄主义
- **细节考据**: 装备型号 / 口径 / 射程不能瞎写

## 子类型
- **古代战争**: 冷兵器 / 阵法 / 粮草 / 攻城战
- **抗战 / 解放战争**: 真实背景 (需尊重历史)
- **现代军旅**: 特种兵 / 新兵成长 / 演习与实战
- **兵王退伍**: 都市 + 军人背景
- **科幻军事**: 星战 / 机甲 / 未来陆军
- **二战架空**: 虚构历史节点展开

## 战斗描写模板

### 古代战役
```
战前 (500):  地形 / 天气 / 双方阵型 / 指挥官心理
接战 (300):  前锋接触 / 弓箭齐射
中段 (1500): 关键变数 (伏兵 / 侧翼突袭 / 阵法转换)
结局 (500):  胜负判定 + 将领表现
战后 (200):  损失 / 战利 / 对大局影响
```

### 现代小分队作战
```
任务简报 (300): 地图 / 敌情 / 己方装备 / 时限
渗透 (400): 接近目标 / 侦察
交火 (1500): 具体战术 (火力压制 / 侧翼机动 / 掩护撤退)
撤离 (500): 追击 / 伤员 / 归队
汇报 (300): 战果 / 伤亡
```

## ⚠️ 强制搜索
- 装备: 枪械型号 / 口径 / 射程 / 弹匣容量
- 军衔: 士兵-士官-尉-校-将军制度
- 编制: 班 / 排 / 连 / 营 / 团 / 师 / 军
- 战役史: 时间 / 双方兵力 / 指挥官
- 兵种特点: 坦克装甲 / 战斗机作战半径 / 军舰吨位
- 地形: 山地 / 沙漠 / 丛林 / 城市战 各自战术不同

## 人物配置
- **主角**: 有明确军事身份 (营长 / 班长 / 飞行员 / 特种兵)
- **战友**: 3-5 人, 每人专长不同
- **上级**: 提供任务 + 冲突来源
- **对手**: 要写出专业水平 (不是纸片人), 敌我智商匹配才有张力
- **后方**: 家人 / 恋人 (人情味, 避免全程硬汉)

## 常见坑
- ❌ **一个人干掉一支军队**: 主角即便兵王也要靠战术不是 Rambo
- ❌ **狙击手千米一枪爆头**: 实战狙击 800m 内为主
- ❌ **一枪一个没弹道**: 不写弹道下坠 / 弹药补给
- ❌ **坦克无限开炮**: 弹药基数有限 (T-72 约 39 发)
- ❌ **炸药无限**: 工兵炸药要算量
- ❌ **飞机油不没**: 战斗机作战半径 500-1500km
- ❌ **全员不怕死**: 真实战场有恐惧 / PTSD
- ❌ **敌军降智**: 专业军人哪怕是对手也应有水平
- ❌ **女兵全打扮得漂亮**: 真军人形象不同
- ❌ **战争描写浪漫化**: 要写残酷 (尸体 / 断肢 / 惨叫)

## 世界观字段
```yaml
war_type:        # 战争性质 (正义 / 侵略 / 内战 / 地区冲突)
belligerents:    # 参战方
  - 名称 / 兵力 / 装备水平 / 指挥官
theater:         # 战场
  - 地理 / 气候 / 补给线
doctrine:        # 战术思想 (闪电战 / 堑壕战 / 游击战)
technology:      # 本时代技术 (冷兵器? 热兵器? 机甲?)
command_chain:   # 指挥体系
intelligence:    # 情报机构
```
