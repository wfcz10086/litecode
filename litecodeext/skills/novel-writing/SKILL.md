# Novel Writing Skill

## 核心原则

1. **状态驱动** — 每部小说维护一份 `state.md`, 记录:
   - 人物卡 (姓名/身份/动机/当前位置/关系网)
   - 世界设定 (时间线/地点/规则/能量体系)
   - 剧情进度 (已发生/在进行/未发生)
   - 伏笔清单 (埋在第 N 章, 未回收)
   - 章节索引 (章号 → 摘要 → 字数)

2. **章节文件独立** — 每章一个文件 `ch{NN}.md`, 便于重写/回滚.

3. **重写三种模式**:
   - **replace**: 完全重写整章 (原稿备份到 `ch{NN}.bak.md`)
   - **polish**: 保留剧情, 改语言/节奏/对白
   - **fork**: 从某章开始分叉, 保留旧线到 `ch{NN}.alt.md`

## 目录结构

```
novel/<project-name>/
├── state.md              # 核心状态 — 先读它
├── outline.md            # 大纲 (章节清单 + 一句话摘要)
├── chapters/
│   ├── ch01.md
│   ├── ch02.md
│   ├── ch02.bak.md      # 原稿备份 (重写前自动保存)
│   └── ...
├── characters/           # 人物档案 (复杂人物独立文件)
│   ├── 主角.md
│   └── ...
├── worldbuilding.md      # 世界观 (若需详细)
└── notes.md              # 作者备忘 / 灵感碎片
```

## 工作流

### A. 新建小说
1. 询问用户: 题材 (玄幻/都市/科幻/言情)、视角 (1st/3rd)、目标字数
2. 创建目录结构
3. 写初版 `state.md` (人物/设定/三幕结构)
4. 写 `outline.md` (10-30 章的一句话摘要)
5. 开始写第 1 章

### B. 续写章节
1. **必读**: `state.md` + `outline.md` + 最近 2 章
2. 按 outline 的 N+1 章摘要展开
3. 写完后:
   - 更新 `state.md` 人物位置 / 剧情进度
   - 在 `outline.md` 标记已完成
   - 新伏笔加入清单, 回收的伏笔打勾

### C. 章节重写 (核心能力)
用户说 "重写第 5 章" 或 "第 5 章太拖沓, 改紧凑点":
1. **备份**: `cp ch05.md ch05.bak.md` (永远备份)
2. 读 `ch05.md` 原稿 + `state.md` 相关剧情 + 前后章 (04/06)
3. 询问重写目标: 剧情不变改语言 (polish) / 完全重写 (replace) / 分叉 (fork)
4. 写新版 `ch05.md`
5. 若剧情改动影响后续, 告知用户哪些后续章节需要联动调整

### D. 状态快照
用户问 "现在写到哪了":
- 输出 `state.md` 中 "当前剧情点", 最近章节摘要, 下一章计划, 未回收伏笔数

## state.md 模板

```markdown
# <小说名> · 状态

## 当前剧情点
第 X 章结束: <一句话状态>

## 人物
| 姓名 | 身份 | 当前状态 | 与主角关系 |
|------|------|---------|-----------|

## 世界
<三段: 时间/地点/规则>

## 伏笔清单
- [ ] 第 2 章: <伏笔描述> — 未回收
- [x] 第 5 章: <伏笔描述> — 第 12 章回收

## 章节索引
| 章 | 标题 | 字数 | 摘要 | 状态 |
|----|------|------|------|------|
| 01 | ... | 3000 | ... | ✓ |
```

## 反模式

- ❌ **不读 state 就写新章** — 人物会出现在错误地点 / 时间线错乱
- ❌ **重写不备份** — 用户改主意没原稿可回滚
- ❌ **一次写 5 章不更新状态** — 伏笔和角色一定会漏
- ❌ **用 `write_file` 覆盖已有章节** — 先看 `ls` + `read` 再决定重写/续写

## 与其他 skill 的配合

- 长章节 (>8000字) 用 `longtext-processing` 切片处理
- 需翻译到其他语言: `longtext-processing` 逐段翻译
- 输出成 docx/pdf 发给出版方: `docx` / `pdf` skill
