# 西方奇幻规范

## 与东方玄幻的核心区别
| 维度 | 玄幻 (东方) | 西幻 (西方) |
|---|---|---|
| 主角修炼 | 境界层级 (练气 → 飞升) | 职业等级 (战士 Lv1-20) |
| 力量源 | 灵气 / 真气 | 魔力 / 神恩 |
| 种族 | 人族为主 | 多种族平等 (人 / 精灵 / 矮人 / 兽人) |
| 神系 | 道佛 / 天道 | 多神教 (善恶阵营) |
| 美学 | 道袍 / 飞剑 / 山水 | 铠甲 / 巨剑 / 城堡 |
| 金手指 | 老爷爷 / 系统 | 神选 / 血脉 / 禁忌魔法 |

## 职业体系 (DND 风)
```
战斗系:  战士 / 圣骑士 / 游侠 / 野蛮人
法术系:  法师 / 术士 / 巫师 / 吟游诗人
神术系:  牧师 / 德鲁伊 / 圣武士
技巧系:  盗贼 / 刺客 / 僧侣
```
每个职业有技能树 / 专精 / 进阶 / 转职.

## 种族设定 (经典 6 种)
```
人类:     适应性强, 什么都能做, 寿命 70-80
精灵:     优雅 / 弓箭 / 自然魔法, 寿命 500+
矮人:     矿业 / 铸造 / 坚韧, 寿命 200
兽人:     野蛮 / 力量 / 部落, 寿命 40
半身人:   机敏 / 潜行, 寿命 100+
龙/半龙:  稀有 / 强大 / 古老, 寿命数千
```
写作前需要选择哪些种族存在, 不一定全要。

## 魔法体系 (选其一)
- **自由法术**: 每个法师能学各种法术 (D&D 风)
- **特化法派**: 法师只能学一个学派 (火 / 冰 / 死灵)
- **符文体系**: 必须画符文才能释放
- **契约体系**: 与恶魔 / 精灵 / 神明签约
- **血脉体系**: 天生就有魔法 (《冰火》龙血)

## 神系
- **多神体系**: 光明神 / 战神 / 死神 / 狂欢神 ... (各有教会 / 圣地)
- **善恶二元**: 光 vs 黑暗 (《魔戒》风)
- **神隐**: 神明存在但不介入 (《冰火》风)

## 人物配置
- **主角**: 要有职业 (新手 / 非主流 / 转职特殊)
- **团队**: 4-6 人 DND 式 (坦克 + DPS + 治疗 + 辅助)
- **导师**: 老法师 / 教官 / 游侠前辈
- **恶役**: 死灵法师 / 恶龙 / 堕落骑士 / 黑暗领主
- **NPC**: 酒馆老板 / 商人 / 国王 / 公主

## 战斗描写要点

### 团队配合 (DND 风精髓)
```
✅ 好:
"矮人 Thorin 举起战斧上前挡住巨龙的扑击, 精灵弓手 Elara 在后方拉满弓弦
三连射, 射向龙眼. 法师 Kilian 低声吟诵火焰冲击, 从龙腹下方爆发.
牧师 Marsh 则施展圣光护盾, 保护了战斗中冲前的圣骑士."

(多角色同框, 技能搭配, 画面感强)

❌ 烂:
"主角一剑砍死了龙."  (没团队感, 等于玄幻)
```

## 常见坑
- ❌ **东西方名称混淆**: 精灵叫"剑仙", 魔法叫"真气" — 违和
- ❌ **等级通货膨胀**: Lv 1000 战士 (D&D 最高 20)
- ❌ **地图瞎画**: 亚尔夫海姆 / 米德加德 都是北欧词, 要查对
- ❌ **神名乱借**: 宙斯 + 奥丁 + 佛陀同一个世界观 (除非主题就是"多神共存")
- ❌ **种族刻板**: 矮人只会喝酒 / 精灵只会冷傲
- ❌ **全人族气质**: 写出来所有种族都像人类 (要有生物学差异)
- ❌ **骑士乱穿铠甲**: 不同时代铠甲样式不同 (板甲是 14 世纪后)
- ❌ **武器瞎配**: 双手巨剑不能单手挥, 长枪不能室内战
