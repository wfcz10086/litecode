# 认知偏差检查

偏差不是"笨", 是大脑的默认省力模式。检查的目的不是给人贴标签, 而是对**这一次具体判断**找出可能的偏差, 并给出能马上做的去偏动作。

## 第 1 步: 写下待检查的判断

```
判断/决定: ____
当前倾向: ____ (信心 0~100%: __)
是怎么得出的: ____ (看了什么、听了谁、想了多久)
情绪状态: 兴奋 / 焦虑 / 愤怒 / 疲惫 / 平静
已投入: 时间 __ 金钱 __ 面子/公开承诺 __
```

## 第 2 步: 12 种高频偏差逐条对照

只把**有本案证据**的标为"命中", 没有就写"未见", 不要硬套。

| # | 偏差 | 典型症状 (自问) | 去偏动作 |
|---|---|---|---|
| 1 | 确认偏误 | 我找的资料是不是都在支持我? 有没有认真看过反对意见? | 专门搜一次"<观点> 反对/失败/风险", 写出最强反方 3 条 (可调 red-team) |
| 2 | 沉没成本 | "都投了这么多了" 是不是理由之一? | 假设今天从零开始、之前投入为 0, 还会选这个吗? |
| 3 | 锚定效应 | 第一个听到的数字 (报价、估值、预期) 有没有一直影响我? | 不看锚点, 独立估一次; 或从相反方向的锚点再估一次 |
| 4 | 可得性偏差 | 是不是因为最近看到一个生动案例/新闻? | 查基础比率 (调 calibrated-forecast), 问"这类事一般多常见" |
| 5 | 过度自信 | 我的区间是不是太窄? 上次类似判断准吗? | 把区间放宽到"错了会很惊讶"的程度; 回看历史记录 |
| 6 | 计划谬误 | 工期/预算是不是按一切顺利估的? | 找同类项目的实际耗时, 乘以历史超支比例 |
| 7 | 幸存者偏差 | 我看到的是不是只有成功者? | 问"失败的那些人去哪了, 他们做了什么不同的事" |
| 8 | 从众/权威 | 是因为大家都这么做, 或某个大人物这么说? | 去掉"谁说的", 只看论证本身是否成立 |
| 9 | 损失厌恶/现状偏好 | 不改变的唯一理由是"改变有风险"? | 把"维持现状"也当成一个主动选项, 列它的风险 |
| 10 | 情绪/热状态 | 现在是不是在愤怒、兴奋、疲惫时做决定? | 能等就等 24 小时; 写下决定, 冷静后再读一遍 |
| 11 | 叙事谬误/后见之明 | 我是不是编了一个很顺的因果故事? | 列出 2 个同样能解释现象的其他故事 |
| 12 | 激励与利益冲突 | 给我信息/建议的人, 从我的决定里获利吗? 我自己呢? | 找一个没有利益关系的人的意见 |

## 第 3 步: 输出体检单

```markdown
# 偏差体检: <判断>
| 偏差 | 命中? | 本案证据 (具体到原话/事实) | 去偏动作 | 做完后结论变了吗 |
|---|---|---|---|---|

## 去偏后的判断
- 原倾向: ____ (信心 __%)
- 去偏后: ____ (信心 __%)
- 变化原因: ____
## 还需要补的信息
## 冷静期建议: 现在决定 / 24 小时后决定 / 等 <事件> 后决定
```

## 纪律

- 不说教, 不羞辱; 措辞用"这里可能有 X 的影子, 证据是……", 不用"你犯了 X 错误"。
- 偏差检查也会被滥用来否定一切: 命中偏差 ≠ 结论错, 只是需要用去偏动作再验证一次。
- 检查 AI 自己的回答时同样适用: 重点看第 1、5、11 条 (只找支持证据、过度自信、故事太顺)。
- 命中 3 条以上且涉及单向门 (不可逆) 决定时, 明确建议"先别决定", 并给出下一步最便宜的验证动作。
