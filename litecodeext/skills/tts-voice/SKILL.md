# 文字转语音 (text_to_speech)

## Keywords
朗读 读出来 念出来 配音 语音合成 文字转语音 tts 音色 语音播报 有声 男声 女声 粤语 晓晓 云希 云扬

## 怎么做
1. 直接调 `text_to_speech(text=..., voice=...)`; 工具不在列表里先 `enable_tools(groups=["voice"])`。
2. 回复里**写出工具返回的完整路径** (网页据此显示 ▶ 播放器 + ↓ 下载); 微信/企微会话再写一行 `[发送文件: 路径]`。
3. 用户没指定音色: 中文用晓晓 (女) / 云希 (男), 英文用 Jenny / Guy。拿不准有哪些音色 → `action="voices"`。

## 音色速查 (edge-tts, 免 key)
| 叫法 | 音色 | 适合 |
|---|---|---|
| 晓晓 | 女, 温暖知性 | 通用首选 / 情感 / 生活 |
| 晓伊 | 女, 活泼 | 种草 / 冷知识 |
| 云希 | 男, 阳光讲故事 | 故事 / 解说 |
| 云扬 | 男, 新闻播音 | 新闻 / 科普 |
| 云健 | 男, 沉稳有力 | 体育 / 纪录片 |
| 晓佳 (HiuGaai) / 云龙 | 粤语 | 粤语内容 |
| 晓臻 (HsiaoChen) | 台湾腔女声 | 台湾腔 |
| Jenny / Guy / Aria | 美式英语 | 英文 |

- 晓萱/晓辰/晓涵等是 Azure 付费音色, edge-tts 不提供, 会自动换成最接近的晓晓并在结果里提示。
- 配了阿里百炼 key 时可用百炼 qwen3-tts-flash 音色 (更自然, 带方言): 芊悦(Cherry)、晨煦(Ethan)、苏瑶(Serena)、
  北京-晓东(Dylan)、上海-阿珍(Jada)、四川-晴儿(Sunny)、粤语-阿强(Rocky)… `voice` 填中文名或英文名即可, 或 `engine="dashscope"`。

## 参数
- `rate` 语速: `"+20%"` 更快, `"-15%"` 更慢, 也可写倍速 `"1.2"`; `pitch` 音调 `"+5Hz"`; `volume` 音量 `"+10%"`。只对 edge-tts 生效。
- `format`: mp3 (默认) / wav / m4a。
- 长文本自动按句切成 ≤300 字一段合成后拼接; 单次上限 1 万字, 更长的分章节多次调用。

## 不适用
- 要字幕、画面、BGM 的成片 → `video-studio` 技能 (它也用 edge-tts, 带逐句时间戳)。
- 声音克隆 → 不在本工具范围。
