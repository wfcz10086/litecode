# 言情题材写作规范

## 核心 — 女频与男频的本质区别
- **人物弧线 > 金手指**: 读者看的是"感情如何发生", 不是"打败多少对手"
- **细节密度 > 爽点密度**: 一个眼神 / 一次触碰 / 一句台词, 都要精雕
- **女性视角**: 描写衣着 / 环境 / 氛围比男频细得多
- **情感推进有节奏**: 从陌生 → 关注 → 试探 → 告白, 不能快进
- **甜 / 虐 / 治愈** 三种路线不能混

## 常见子类型

### A. 甜宠
- 轻松日常 + 无大反派 + 误会立刻解开
- 每 500 字一个甜点 (撒糖)
- 主角对感情直接不拖延
- 读者要"磕糖上瘾"

### B. 虐恋
- 前期虐主 / 虐受 / 虐互虐
- 误会累积, 不立刻解开
- 后期必须"治愈"或"圆满"
- 心理描写密度非常大

### C. 破镜重圆
- 前任 + 离婚 / 分手 多年
- 命运安排重逢
- 逐步重新了解对方 (对比当年)
- 最后和好 / 再婚

### D. 先婚后爱
- 契约婚姻 / 指腹为婚 / 包办婚姻
- 婚前陌生 → 婚后相处 → 渐生情愫
- 第一次的心动瞬间是全书爆点

### E. 校园
- 暗恋 / 青梅竹马 / 学霸学渣
- 时代背景要准 (90 后 / 00 后 不同氛围)
- 毕业 = 第一幕结束, 成年后重逢是第二幕

### F. 豪门总裁 (最大套路)
- 霸道总裁 + 灰姑娘 / 娇妻 / 失忆前妻
- 家族斗争 / 豪门恩怨
- **慎重**: 这类套路已严重透支, 必须"翻新点"才有看头

## 人物配置
- 女主: **绝对不能"又白又瘦又漂亮人人爱"** — 必须有瑕疵 / 缺点 / 挣扎
- 男主: 同理, 不能全是"霸道高冷", 要有"软弱时刻"
- 前任 / 情敌: 不是纯恶, 要有立体原因
- 闺蜜 / 兄弟: 1-2 位推进剧情, 不要人设重复

## ⚠️ 禁忌 (读者最恨)
- ❌ "强吻强行 XX" (没 consent 的亲密描写, 翻车重灾区)
- ❌ 女主智商下线 (别人说啥信啥 → 读者会骂)
- ❌ 全篇心理活动 (没对话没行动, 乏味)
- ❌ 男主越虐越深情 (煤气灯叙事, 不符合现代读者)
- ❌ 套路"车祸 + 失忆 + 绝症" 三件套
- ❌ 女性角色互相拉踩 (不要让女二永远是恶毒女配)

## ⚠️ 强制搜索 (现代言情)
- 品牌 (lululemon / MCM / 始祖鸟) 价位
- 职业细节 (医生/律师/投行的真实工作)
- 城市地标 (上海外滩 / 北京三里屯)
- 最新流行 (梗 / 热点 / 网络用语)

## 章节模板 (3000 字, 密度大)
铺垫 (400) → 相遇/相处 (1000) → 心动瞬间 (600) → 冲突或甜蜜 (700) → 心理留白 (300)

## 描写要点 — 细节之神
```
✅ 好的言情描写:
"她推开门的那一刻, 看见他站在窗边. 夕阳把他的衬衫染成金色, 袖口挽到手肘,
露出腕上那块旧表 — 是她送的那块, 她以为他早就丢了."

❌ 差的言情描写:
"她看见他站在那里, 心里一动. 他果然还记得她."
```

## 套话黑名单
- "心脏漏了一拍"
- "瞳孔一颤"
- "他的眼底翻涌着情绪"
- "霸道地吻上去"
- "把她禁锢在怀里"
- "一脸生人勿近"
- "整个世界都静止了"
- "千言万语"
- "百转千回"

## 世界观字段 (言情的"世界观"是家庭 + 社交圈)
```yaml
era:          # 时代
setting:      # 城市 / 大学 / 公司
family_bg:    # 女主家庭 / 男主家庭 (冲突源)
work_bg:      # 职业 (决定日常场景)
social_circle:# 朋友圈 (闺蜜 / 兄弟)
secrets:      # 身世秘密 / 误会 (伏笔)
```
