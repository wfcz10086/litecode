# 武侠题材写作规范

## 核心精神 (与玄幻/修真的根本区别)
- **没有修炼境界数字**, 用"三流高手 → 二流 → 一流 → 绝顶 → 宗师" 口语化划分
- **重人情轻升级**, 打斗不是主线, 人物弧线才是
- **家国江湖二元**, 主角往往在朝廷/民族大义与江湖侠义间抉择
- **朴实动作描写**: 招式有名但描写具象, 不堆砌华丽形容词

## 武功体系
```
内功:      长期修炼, 决定内力深厚 (如九阴真经/易筋经)
招式:      具体套路 (降龙十八掌/独孤九剑)
轻功:      身法 (凌波微步/燕子三抄水)
暗器/毒:   辅助手段
```
- **内功比招式重要**: 内力不足, 招式再强也发不出
- 招式名要有古意, 不要太中二 (如"毁天灭地×× 决" 不行; "降龙十八掌" 可以)

## 人物配置
- 主角: 孤儿 / 落魄弟子 / 世家子弟 + 有"情义"底色
- 红颜: 2-3 位 (不要一堆后宫, 武侠讲"情"不是"收")
- 师父: 深刻影响主角三观的导师 (往往亦师亦父)
- 反派: 有血有肉 (理解其行为动机, 不是纯坏)
  - 大反派要有"时代必然性" (野心家 / 偏执者 / 被逼上梁山)
- 路人侠客: 每几章出一位, 推进支线

## 爽点密度 (比玄幻/修真低)
- 每 4000-5000 字一个小爽点 (突破 / 击败敌人 / 得神功)
- 每 10-15 章一个大高潮
- **留白比爽点重要**: 失败 / 退隐 / 悲剧都是卖点

## 套话黑名单
- "XX武林一霸"
- "此乃江湖规矩"
- "大丈夫生于天地间"
- "老子不服"
- "真是奇耻大辱"
- "少年郎不可限量"
- "冷笑一声 + 拔剑"

## 章节模板 (每章 3000 字)
情境设置 (500) → 对话/冲突铺垫 (1500) → 动手/决断 (700) → 余韵 (300)

## 典型情节模板
1. 路见不平 → 出手 → 被误会 → 澄清 → 结交
2. 寻仇被败 → 奇遇 → 十年后归来 → 成功复仇 → 发现当年有误
3. 两派争斗 → 主角中立 → 卷入 → 被迫站队 → 终结
4. 神功残缺 → 遍寻下卷 → 集齐 → 发现功法有诅咒

## 世界观字段
```yaml
era:         # 朝代 (宋/明/清/虚构)
geography:   # 中原 / 塞外 / 江南 / 大漠 / 海外
factions:    # 门派
  - 正派: 少林/武当/华山/峨眉/崆峒
  - 魔教: 明教/日月神教
  - 朝廷: 锦衣卫/东厂
ethics:      # 江湖规矩
  - 不伤无辜 / 不欺老弱 / 快意恩仇
family:      # 主角家世 (铺垫身世之谜)
```

## 禁忌
- ❌ 数字境界 (不能"突破到练气 9 层")
- ❌ 系统提示 (武侠没系统, 有系统去写 novel-xitongliu)
- ❌ 穿越自白 (主角可以穿越, 但不能动不动提前世)
- ❌ 女主全"倾国倾城" (至少一位有瑕疵或平凡)
- ❌ 最终大 Boss 是"魔神" (武侠没神怪, 最多是走火入魔的高手)
