# 历史题材写作规范

## 史实红线 (不能踩)
- ❌ **改变重大历史结局** (不能写"赤壁之战曹操胜") — 架空也不行, 会被历史爱好者围攻
- ❌ **知名人物性格大反转** (不能把诸葛亮写成反派, 除非明确"戏说")
- ❌ **时代错乱** (唐朝不能有辣椒 / 明朝不能有 iPhone, 穿越者除外)
- ❌ **官职乱用** (唐朝的"中书令"不等于明朝的"内阁首辅")

## ⚠️ 强制搜索 (本题材最严)
**每涉及一项史实必须 web_search 确认**:
- 具体年份 / 月份 / 事件
- 官职 / 爵位 / 品级
- 服饰 / 食物 / 钱币 (唐朝用"开元通宝"不是"铜钱")
- 地理 (古地名 / 当时疆域)
- 典章制度 (选官 / 赋税 / 兵制)

建议用 `web_search` 查 "X 朝 Y 制度", 每章至少 2-3 条史实引用。

## 常见子类型

### A. 穿越汉唐 (主流)
- 穿到知名人物身上 (如穿成李世民 / 刘秀 / 霍去病)
- 或穿到普通人 (靠知识改变命运)
- 金手指: 历史知识 / 现代科技 / 心理学

### B. 架空历史
- 完全虚构朝代, 但参考真实朝代气质
- 自由度大, 但要自洽
- 难点: 架空世界观需要全套铺设

### C. 民国
- 1912-1949, 军阀混战 + 革命 + 抗战
- 特别: 西装旗袍并存 / 东西文化碰撞 / 特务战
- 语言风格可以"半文半白"

### D. 三国
- IP 重度饱和, 要"新角度"
- 比如: 穿成关平 / 马谡 / 曹植 (非大热角色)
- 对三国志 / 三国演义 至少要读过一本

## 人物配置
- 主角穿越者需**谨慎暴露现代知识** (说多必翻车)
- 每章至少 1 位真实历史人物 (戏份少无妨, 要写得准)
- 配角可自由虚构, 但要符合时代

## 爽点
- 预测大事件 (例: 告诉唐太宗"明年泾阳必旱")
- 提前布局 (知道武则天要夺权, 布政治局)
- 用现代知识解难题 (造纸 / 火药 / 算术)
- ⚠️ 不要一次全爆 (主角越懂越要藏着, 合理分批用)

## 语言风格
- **避免两种极端**: 不能全文白话 (失古味) / 不能全文古文 (看不懂)
- 对话可半文半白: "李兄今日可有安排"
- 叙述用现代白话
- 官方文书 / 诏书可用文言
- 避免现代词汇漏出 (不能说"心态炸了""打卡")

## 套话黑名单
- "这货不是穿越来的吧" (太穿越文了)
- "历史终将铭记" (俗套)
- "想不到区区一介布衣"
- "大丈夫生于天地间"
- "皇上英明"
- "臣万死不辞"

## 世界观字段
```yaml
dynasty:     # 朝代 / 时代
year:        # 具体年份 (不能"大概是唐朝")
ruler:       # 当朝皇帝
major_events:# 本时代大事件时间轴
geography:   # 当时疆域 / 重要城市
institutions:# 官职 / 税制 / 兵制
customs:     # 风俗 (冠礼 / 婚俗 / 丧葬)
```

## 禁忌
- ❌ 不查直接写 ("南宋时代的北京" — 北京当时叫金中都)
- ❌ 朝代混搭 ("唐朝茶艺" + "宋朝官制" 乱炖)
- ❌ 过度黑白二分 (历史人物有复杂性)
- ❌ 忽视女性地位 (古代女性困境要如实反映)

## 参考标杆
《明朝那些事儿》(标杆) / 《宰执天下》《新宋》《唐砖》《庆余年》(架空, 但考据精)
