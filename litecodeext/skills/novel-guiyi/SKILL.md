# 诡异题材写作规范

## 核心气氛 (与其他题材本质区别)
- **气氛 >> 剧情**, 读者买的是"冷汗"和"毛骨悚然"
- **解释要慢 / 不要完整**: 全解释清楚就不恐怖了, 保留 30-50% 神秘
- **主角不是越战越强**, 而是越调查越发现自己渺小
- **基调: 压抑 + 潮湿 + 阴冷**, 描写多用黑 / 灰 / 红

## 常见子类型

### A. 民俗怪谈 (中式灵异)
- 纸人 / 赶尸 / 鬼嫁 / 阴婚 / 血咒 / 风水
- 场景: 村庄 / 老宅 / 乡下丧事 / 城中村
- 金手指: 祖传道术 / 天眼 / 异骨

### B. 规则怪谈 (新兴流派)
- 给出一组看似平常但有诡异漏洞的规则
- 例: "在 3 楼出电梯, 永远往左走, 记住不能数到 4"
- 主角在规则缝隙中求生, 违反一条 = 死/消失

### C. SCP / 克苏鲁
- 异常实体 (存在 = 污染现实)
- 组织 (基金会 / 教廷 / 神秘学会)
- 理智值 (SAN) 系统 (归零就疯)
- 不可名状描写: 多用"仿佛 / 似乎 / 说不上来" 等模糊词

### D. 都市灵异调查
- 主角当代人 (警察 / 记者 / 学生) 卷入诡异事件
- 气氛偏悬疑, 逐步揭露真相
- 结局不一定 happy ending

## 爽点 (诡异的"爽"很特殊)
- **揭秘瞬间**: 之前的诡异细节突然闭环
- **以诡制诡**: 用规则对付规则, 而不是暴力
- **命悬一线**: 主角差点死, 靠智谋脱险
- **余味**: 结束后主角不是毫发无伤, 留下改变/印记

## 描写技法 (本题材灵魂)

### 感官优先
```
✅ "墙上的水渍缓缓从上往下流, 闻着像铁锈"  (视觉+嗅觉)
❌ "那东西很诡异"                        (抽象, 无感)
```

### 细节违和
```
✅ "她冲他笑, 嘴角上扬到了耳根, 眼睛却一眨不眨"  (具体异常)
❌ "她看起来很可怕"                              (空洞形容)
```

### 节奏控制 — "铺垫三倍长于爆发"
```
3000 字一章:
   铺垫 (2000)  : 日常 → 小违和 → 累积不安
   发现 (600)   : 异常暴露
   反应 (300)   : 主角挣扎
   留白 (100)   : 戛然而止或开放结尾
```

## 套话黑名单 (本题材特别警惕)
- "毛骨悚然 / 不寒而栗 / 汗毛倒竖" (滥用就麻木)
- "诡异之极"
- "一阴风吹过"
- "她的眼睛直直盯着我"
- "空气仿佛凝固了"
- "一股冷意从脚底升起"
- "那东西不知道是什么"

> 诡异描写**不要说"诡异"**, 用具体细节让读者自己感到诡异。

## 规则怪谈专属模板
```markdown
## 【新手入住须知】

1. 房间白天是 502, 晚上可能是 503, 请注意门牌号.
2. 不要和镜子里的自己对视超过 10 秒.
3. 22:30 开始, 走廊里可能出现第 8 个身影. 你如果是第 8 个, 请立即回房.
4. 听到敲门声三下不要开门, 问"谁".
5. 违反以上规则, 后果自负.

规则背后:
- 房间号变化 = 另一维度叠加
- 镜子里 = 自己的"替身"在等时机
- 8 人 = 楼里实际住户数
- 敲门三下 = 它想确认你是人
```

## 禁忌
- ❌ 主角变强后"一拳打爆鬼" (违背诡异世界观, 那是玄幻)
- ❌ 全解释清楚 (留 30% 不可知)
- ❌ 大开金手指 (天眼可以, 金钟罩不行)
- ❌ Happy ending (最多 bittersweet, 正统诡异是悲/虚无结尾)
- ❌ 套用"鬼是弱的, 神是强的"层级观念
- ❌ 过度色情描写 (诡异气氛会崩)

## 世界观字段
```yaml
anomaly_type:    # 异常类型
  - 实体 / 现象 / 污染 / 规则 / 认知
realms:          # 层次 (只暗示, 不明确)
  - 现实 / 隔层 / 深渊
organizations:   # 神秘学组织
  - 基金会 / 邪教 / 退休的"知情者"
rules:           # 世界规则 (不全公开)
  - "凝视 = 被凝视"
  - "命名 = 召唤"
currency:        # 代价货币
  - 理智 / 寿命 / 名字 / 记忆
```
