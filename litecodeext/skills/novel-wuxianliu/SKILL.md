# 无限流写作规范

## 核心机制 ("主神空间"模板)
```
主神 (或系统) 把主角拉进副本 → 副本是电影/游戏/历史/原创世界 → 完成任务 → 返回主空间
主空间: 能力评级 / 兑换奖励 / 队友匹配
副本: 每个规则不同, 但都是"恐怖/冒险"的变体
```

## 副本选择 (IP 致命)
- ✅ **原创**: 自己编的世界 (安全, 但需要建构)
- ⚠️ **公版**: 过期版权 (《西游记》《三国》《狄更斯》) OK
- ❌ **现代 IP**: 不要用《鬼吹灯》《盗墓笔记》/ 不要用《生化危机》, 要改名 (如"生化威机" / "秦王陵笔记")
- ❌ 真人真事 (法律风险)

## 副本类型
```
恐怖类:   鬼怪 / 丧尸 / 连环杀手  (占 40%)
冒险类:   末世 / 异世界 / 盗墓        (占 30%)
历史类:   古代战场 / 历史事件       (占 15%)
原创类:   异星 / 修仙 / 武侠       (占 15%)
```

## 主空间体系
```
评级:      新手 / 青铜 / 白银 / 黄金 / 铂金 / 钻石 / 王者 (可换皮)
积分:      完成任务 / 活下来 得到, 可兑换奖励
属性点:    力/敏/智/体, 永久提升
商城:      武器 / 药品 / 技能 / 情报 / 血统 / 法则
队伍:      3-5 人固定小队 (老队友) + 副本临时队友
```

## 人物配置
- 主角: 第一次被拉进副本的普通人 / 有前世经验的重生者
- 核心队友 3-5 人: 专长差异 (战斗 / 情报 / 医疗 / 灵异)
- 副本原住民: 角色设定参考原著
- 大反派: 副本 Boss (单副本) + 主神 (终极, 通常是全系列最后)

## 爽点公式
```
副本启动 (恐怖) → 摸清规则 (紧张) → 获得道具/队友 (铺垫) → Boss 战 (爽) → 主空间奖励 (满足)

每 3-5 章一个副本起止
每 10-20 章一个大副本 (世界级 BOSS)
```

## 套话黑名单
- "主神空间万岁"
- "咸鱼翻身"
- "我们是回来的老队友"  (次数过多)
- "这是一个 XX 级副本"
- "无限世界的残酷规则"
- "只有强者才能活下去"

## 副本写作模板 (每副本 5-10 章)
```
Ch1 副本启动: 主神讲解任务 / 空间投放
Ch2 探索世界: 了解原著 / 找到关键 NPC
Ch3 规则揭示: 死亡条件 / 过关条件
Ch4-5 冲突升级: 队友矛盾 / 敌人变强
Ch6 Boss 战: 决战
Ch7 返回主空间: 结算奖励 / 反思成长
```

## 禁忌
- ❌ 用现代 IP 不改名 (法律)
- ❌ 主角一副本就通关 (没张力)
- ❌ 所有副本都是主角带飞 (老队友要成长 / 死亡 / 背叛)
- ❌ 主神全知全能干预 (违反"无限流"自由度精神)
- ❌ 道具通胀 (后期人手一件神器, 没代入感)
