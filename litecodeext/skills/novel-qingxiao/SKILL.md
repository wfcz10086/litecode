# 二次元轻小说规范

## 核心气质
- **人设 > 剧情**: 角色要让读者"萌"或"欲"
- **视觉化描写**: 想象读者脑补成插画
- **高频对话**: 对话占全文 40-60%, 远高于传统小说
- **快节奏**: 每章有信息量 + 爽点, 不注水
- **标签化**: 傲娇 / 三无 / 腹黑 / 天然呆 / 元气 — 人设贴标签易读

## 常见子类型
- **异世界转生**: 主角死后转生到魔法世界
  - 金手指: 系统 / 转生前记忆 / 天赋异常
- **校园日常**: 高中生 + 社团 + 恋爱
- **偶像**: 女团 / 男团 / 演艺圈 (《LoveLive!》风)
- **魔法少女**: 战斗 + 日常二线
- **后宫轻小说**: 男主身边一堆女孩 (慎写, 雷区多)
- **百合 / 耽美**: 同性情感 (小众但忠实)

## 人物配置 (标签化)
每个角色配 **2-3 个标签** (读者 3 秒能记住):
```
女主 A: 傲娇 + 大小姐 + 贫乳  (《凉宫春日》)
女主 B: 三无 + 银发 + 御宅
女主 C: 元气 + 运动 + 吃货
男主: 钝感 + 好人 + 平凡 (主角要"空白"让读者代入)
配角: 腐女闺蜜 / 严厉学姐 / 呆萌学妹
```

## 章节模板 (节奏比传统快)
```
2000-3000 字 / 章:
开头 (300): 吐槽 / 抱怨 / 日常对话
事件 (800): 突发状况 / 意外相遇 / 任务
互动 (1000): 角色化学反应 (必须有 ≥ 2 位角色同框)
爽点 (400): 卖萌 / 福利 / 哭点 / 反转
悬念 (200): 下章钩子
```

## 描写要点

### 视觉化 (脑补成插画)
```
✅ 好:
"她穿着白色长裙从樱花树下走来, 发丝随风扬起, 左手还拿着半杯没喝完的
抹茶拿铁. 阳光穿过花瓣, 在她肩上落下斑驳光影."

(直接想象成插画场景)

❌ 烂:
"她走来了, 很漂亮."
```

### 日系对话 (口头禅 / 吐槽)
```
✅ 好:
"呐~今天也元气满满地吃早餐吧!"
"(……) (……)"  (三无角色的沉默)
"真是的, 你这家伙总是这样..."  (傲娇的口头禅)
```

## 爽点密度 (比男频小说还高)
- 每 500-800 字一个笑点 / 萌点 / 反差
- 每 2 章一次"心动瞬间" (情感推进)
- 每 5 章一次大事件

## 常见坑
- ❌ **人设重复**: 一堆傲娇 / 一堆三无
- ❌ **主角太完美**: 轻小说男主通常是"钝感普通人"
- ❌ **开篇不吐槽**: 轻小说第一段就要有梗
- ❌ **世界观硬塞**: 要让它自然漏出, 不要开章讲设定
- ❌ **翻译腔过重**: "请不要说那种话" → "别说这种话"
- ❌ **福利过度**: 软色情堆砌 (日轻翻车常见)
- ❌ **严肃场面太长**: 轻小说需要轻松调剂
- ❌ **结尾悲剧**: 读者不吃这套 (除非类型就是虐系)

## 日系专属套话黑名单
- "呐~" 用多
- "请不要这样"  (翻译腔)
- "为什么一定要"  (过度抒情)
- "仿佛整个世界"  (太宏大)
- "心脏扑通扑通" 滥用
- "好羞耻啊"

## 轻小说独有元素
- **口头禅**: 每个角色一两句标志性台词
- **内心吐槽**: 主角的内心 OS (占 20-30%)
- **卷末角色介绍**: 新角色登场插一段档案页
- **作者后记**: 每卷末轻松吐槽
- **插图**: 标注"这里插图" (纸质版要用)

## 世界观字段
```yaml
setting:      # 场景 (校园 / 异世界 / 都市奇幻)
genre_subtype:# 子类型
protagonist_type: # 主角类型 (普通/转生/异能)
power_system: # 如有异能
  - 魔法体系 / 职业分类 / 等级
main_cast:    # 核心女/男角色 (3-5 位)
trope_bingo:  # 用了哪些轻小说梗
  - 转生 / 后宫 / 成神 / 系统 / 班级穿越
```
