# 电竞题材写作规范

## 核心
- **游戏知识准确** — 一句写错会被读者喷
- **操作描写**: 不能全是"走位 / 技能一连招", 要写出"手速 / 意识 / 决策"
- **热血 + 青春** 气质为主

## ⚠️ 强制搜索 (本题材绝对红线)
每写游戏操作前:
- web_search 英雄/武器 当前版本技能
- web_search 比赛规则 (BP / 模式 / 胜负判定)
- web_search 专业术语 (gank / 打野 / 反野 / 团战)
- 如果是虚构游戏: 在 world_bible 里写清规则, 全文不能改

**真实游戏引用**: 避免写"国内最大俱乐部 EDG" (真实战队容易翻车), 用化名"EDH"

## 选题
### A. 职业选手类
- 主角入选战队 → 队内竞争 → 常规赛 → 季后赛 → 世界赛
- 节奏: 一个赛季 = 一卷, 约 80-100 章
- 必备: 教练 / 经理 / 队友性格鲜明

### B. 主播类
- 主角从素人到头部主播
- 副本: 直播事故 / 粉丝互动 / 广告合作
- 爱情线: 女粉 / 女主播同行

### C. 游戏内冒险 (网游小说)
- 《全职高手》模式
- 游戏世界几乎独立于现实
- 金手指: 高操作 / 绝版英雄 / 前世经验

## 比赛描写模板 (写法最关键)
```
赛前 (500字):  选手状态 / BP 博弈 / 心理博弈
开局 (500字):  前期布局 / 经济对比
中期 (1000字): 3-5 次小团战 / 关键技能释放 / 装备变化
决战 (800字):  最后一波团 / 操作高光 / 胜负判定
赛后 (200字):  情绪 + 下一场钩子
```

## 操作描写要点
```
❌ 烂: "他放出技能, 击杀了对手"
✅ 好: "他在对手交出闪现的瞬间, Q 技能预判到了即将到达的落点. 0.3 秒 —
       普攻跟上 + E 技能打断施法, 对手的大招还没放出来就倒地."
```

## 人物配置
- 主角: 天才 / 老将 / 跨界 (三选一, 决定叙事基调)
- 队友 4-5 人: 坦克 / AD / AP / 辅助 / 打野 (对应 LOL), 人设差异化
- 教练: 灵魂角色, 提供战术指导
- 对手: 顶级选手 (像《棋魂》的塔矢亮)
- 女主: 陪伴型 / 对手战队 / 解说 (不要吉祥物)

## 爽点密度
- 每场比赛 = 2-3 章
- 每 3-5 章一次 "高光操作"
- 大赛 (世界赛) 分 15-20 章详细写
- 不要一章打完决赛 (会烂尾感)

## 套话黑名单
- "电竞圈又出新人了"
- "此乃 1v5 翻盘"
- "手速堪比职业"
- "没有人能阻止"
- "操作教科书"
- "对面已破防" (梗用多就腻)

## 世界观字段
```yaml
game:          # 游戏
  - 名字 / 类型 / 规则 / 英雄池
league:        # 联赛
  - 名称 / 规则 / 奖金 / 参赛队伍
team:          # 战队
  - 队名 / 赞助 / 阵容 / 教练组
player_profile:# 选手档案
  - 真名 / ID / 年龄 / 职业经历 / 成名战
```

## 禁忌
- ❌ 操作瞎写 ("开大招消灭全场" — 具体英雄技能冷却呢?)
- ❌ 一场比赛一章打完 (爽点稀释)
- ❌ 用现实战队真名 (法律风险)
- ❌ 女性选手全当花瓶 (现实有 Scarlett / 小苍等标杆)
- ❌ 忽略职业选手的身体 / 心理压力 (真实感关键)
