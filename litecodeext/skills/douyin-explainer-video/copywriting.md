# 口播文案指南

## 第一步: 按题材选风格 (script.json 写 `"style"`, 文案闸会查)
同一套写法套所有题材, 出来就是"念数据表"。先定风格再动笔:

| style | 名字 | 适合题材 | 核心一问 | 结构 (6-8 场) |
|---|---|---|---|---|
| `chaizhang` | 拆账 | 财经 / 经济预测 / 政策 / 行业 | 钱从哪来, 流到谁手里, 谁买单? | 反常识结论 → 因果链 A→B→C → 赢家和输家 → 落到普通人的账 → 一句判断 |
| `benzhi` | 本质拆解 | 社会议题: 彩礼 / 考公 / 内卷 / 就业 / 婚恋 | 表面吵的是什么, 底下算的是什么账? | 现场 → 各方激励 → 结构 vs 个人 (两边都说) → 欲望和面子 → 反转 + 结论 |
| `fangongshi` | 反共识 | 科技 / AI / 互联网 / 新产品 | 宣传说的是 X, 实际是 Y? | 流行说法 → 戳破的证据 → 真正的商业逻辑 → 谁被替代 / 谁收割 → 判断 |
| `fanan` | 翻案 | 历史 / 朝代 / 历史人物 | 教科书漏了什么? | 通行说法 → 被忽略的细节 → 新解释 → 照见今天 |
| `jiemi` | 悬念揭秘 | 冷知识 / 科学 / 自然 | 为什么会这样? | 反直觉问题 → 三步逼近 (每步排除一个错误答案) → 揭晓 → 一个更怪的延伸 |
| `bikeng` | 揭底避坑 | 消费 / 生活 / 行业内幕 | 这钱是怎么从你口袋里出去的? | 一个常见消费场景 → 利润结构 → 行业潜规则 → 普通人怎么不被收割 |
| `lezige` | 乐子哥冷嘲 | 人物 / 国际时政乐子史 | 这人 (这国) 怎么把好牌打烂的? | 见下方「参考风格」 |
| `beiju` | 克制悲剧 | 人物陨落 / 悲剧 | 他赢在哪, 又输在哪? | 见下方「通用爆款结构」, 用反差代替煽情 |

拿不准就按题材关键词选: 涨跌、增速、利率、房价、预测 → chaizhang; 彩礼、考公、躺平、996 → benzhi; AI、芯片、App → fangongshi。

## 尖锐的写法 (所有风格通用; 前 4 条文案闸会查)
1. **每场回答一个"为什么"或"所以呢"**。光报数字不算内容: "美国增速百分之二点三" 是数据, "美国只有二点三, 因为高利率还压着企业借钱" 才是内容。
2. **一场最多一个主数字**。三个数挤一场 = 观众一个都记不住; 留最狠的那个, 讲透它。
3. **禁用废话**: 让我们拭目以待 / 值得关注 / 各有利弊 / 见仁见智 / 不得不说 / 众所周知 / 一起来看看 / 未来可期 / 令人深思 / 有人认为。这些词出现 = 你没想清楚立场。
4. **价值不外包**: 本期最重要的结论 ("跟你钱包有关的") 本期讲完。下期预告只做钩子, 不许把干货推过去。
5. **有立场**: 结尾给判断句 ("这不是复苏, 是分化"), 不给鸡汤, 不和稀泥。
6. **点名利益方**: 谁受益、谁买单 —— 说机构、行业、群体; 对公众人物只评公开言行, 不做人身攻击。
7. **翻译成普通人的账**: 抽象指标落到工资、房贷、存款、饭碗、物价上。没有数字出处就说定性的 ("降息会更慢"), 别编数。
8. **反常识开头**: 第一句说出大多数人想错的那一点 ("回暖的是账本, 不是你的工资条")。
9. **尖锐 ≠ 编造**: 判断可以狠, 事实必须来自 facts。推出来的结论说"按这个逻辑", 别包装成事实。

### 示例: 同一组 facts, 念表 vs 拆账
念表 (原片, 被用户评"没深度"):
> 先说总盘子。国际货币基金组织十月报告: 去年全球增长百分之三点五, 今年只有百分之三点一, 明年回升到三点四。
> …… 关注我, 下期拆这份报告里, 跟你钱包最近的三条。

拆账 (`chaizhang`, 数字全部来自原片 facts):
> s0 明年全球经济回升到百分之三点四。先别高兴: 撑起这个数的, 是人工智能烧的钱, 不是你的工资。
> s1 今年为什么最慢? 因为油。霍尔木兹海峡一出事, 今年油价均价涨了百分之四十一。
> s2 油一贵, 运费、化肥、塑料全跟着涨。全球通胀被推到百分之四点七, 央行就不敢降息, 钱一直贵着。
> s3 那明年靠什么回升? 看账本。高盛测算, 明年科技巨头在人工智能上要砸约1.4万亿美元。
> s4 问题是钱流向哪: 芯片、云厂商、电力, 赢家很集中。美国增速只有百分之二点三, 大部分行业没吃到这口肉。
> s5 落到普通人身上: 通胀回落得慢, 意味着贷款利率也降得慢; 钱往人工智能走, 别的行业过的是紧日子。
> s6 所以二零二七年不是复苏, 是分化。总数在涨, 涨在少数人的账本上。看清钱往哪流, 比盯着增长率有用。

## 参考风格: "绷不住的乐子哥"
2026-10 调研结果: 抖音上没核实到这个号, B站有同名 UP 主 (space.bilibili.com/7772903)。
他的题材是国际时政加人物"乐子史", 比如印度、伊朗、特朗普、硅谷、韩国; 视频时长 4-6 分钟。
拿不到口播原文, 下面的规律是从他 30 条标题和简介里归纳的。

**标题公式: 人设标签 + 冒号 + 两句对仗短语**, 下面都是真实标题:
- 冤种波斯：夺舍起家横跳成瘾，一手好牌打到稀烂
- 特朗普：先天赢学圣体，纽约龙场悟道
- 头号玩家彼得蒂尔，阿美莉卡最神秘的男人
- 硅谷巨骗名人堂：投资人和脑子不会同时存在
- 卷王之王万斯：铁锈带不相信美国梦

**写法要点**
- 先给人物或国家贴一个梗化人设: 冤种、卷王、赢学圣体、头号玩家。
- 拿中国典故和影视做类比: 中东袁绍、龙场悟道、呼保义、《让子弹飞》, 降低理解门槛。
- 四字、七字对仗多, 读起来有节奏。
- 语气是冷嘲加阴阳怪气, 但不骂人。
- 用反讽金句收尾, 例如 "只要我赢的够快，失败就追不上我"。

**怎么用到 1-2 分钟竖屏**
- 他的长视频结构要压缩: 人设钩子 → 3-4 个高光或翻车节点 → 反讽或悲剧金句。
- 梗只做调味, 一场最多一个, 别整段堆梗。
- 悲剧人物 (如利弗莫尔) 收着点, 用反差代替吐槽。
- 吐槽对象只能是公众人物的公开言行, 不碰普通人, 不碰敏感时政立场。

## 通用爆款结构 (同类账号的通用经验, 不是乐子哥本人的写法)
| 段 | 时长 | 写法 | 例 |
|---|---|---|---|
| 钩子 | 0-10s | 反常识结论 + 具体数字 + 悬念, 不说名字 | "股灾里逆势赚走约一亿美元……字条只有一句话" |
| 登场 | 10-25s | 一句话立人设, 一个反差细节 | "十四岁离家出走, 赢到被对赌行集体拉黑" |
| 爽点 | 25-50s | 高光时刻, 数字具体但要核实 | "连摩根都托人捎话: 放过市场" |
| 转折 | 50-70s | 翻车或代价, 节奏放慢 | "看得懂市场, 看不懂自己" |
| 金句 | 70-90s | 反差收尾 + 一句能截图转发的话 | "他战胜了市场, 却输给了自己" |
| 钩下期 | 最后 3s | 关注卡写具体下期内容 | "关注我 · 下期拆他的交易铁律" |

## 事实红线 (factcheck.py 会拦一部分, 剩下靠自觉)
原片踩过的坑, 每条都是真事:
- **"N 年后"自己算一遍**: 1929 → 1940 是 11 年, 不是 14 年。旁白里的相对年份全部由 facts 里的年份推出来。
- **"一天"和"一段时间"别混**: 一亿美元是整个 1929 股灾期间赚的, 不是"最黑暗的一天"。
- **次数类说法各处资料常打架** ("第五次破产"): 拿不准就写"一次又一次"、"再次"。
- **金额写"约"**, 历史金额别换算成"相当于今天几十亿" (换算口径一换差几倍)。
- **查不到出处的细节宁可不要**: 原片的"借 500 美元翻身""3202 号房"都找不到可靠来源, 删了故事一样好看。
- 外号用有出处的: 利弗莫尔是"华尔街巨熊 (The Great Bear of Wall Street)"。

## 句子规则 (TTS 友好)
- 一句 8-20 字, 用逗号断开。edge-tts 碰到长句会一口气念完, 没有停顿。
- **配音按句子起伏 (tts.py 逐句合成)**: 问句自动上扬并在句后停顿留悬念; 带数字 / 高亮词的句子自动放慢;
  ≤10 字的短句前面会顿一下再"砸下来"。所以要**故意写**: 抛一个问句, 再用一句短判断收住 ("今年为什么最慢? 因为油。")。
  一场全是二三十字的陈述句, 念出来就是平的。
- 年份写成汉字: "一九二九年" 比 "1929年" 读得稳。数字可以留阿拉伯数字, TTS 能读。
- 不出现英文 (tts.py 会拦), 外国人名用中文译名。
- 每场 40-80 字, 合 8-16 秒。全片 6-8 场, 总长 60-100 秒。
- 每场至少有一个具体名词: 年份、金额、地名、人名。不要空泛的形容词。

## 标题 (发布包里给 3 个)
1. 数字悬念型: "股灾里赚走一亿美元是什么体验？他赢了市场，输掉了整个人生"
2. 乐子哥人设型: "华尔街巨熊利弗莫尔：先天交易圣体，后天破产专业户"
3. 对比型: "从抄牌少年到华尔街传说：一个天才交易员的完整陨落史"
