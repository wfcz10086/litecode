```
SK=/opt/litecode/skills/douyin-toolkit      # 容器内路径, 所有命令用 execute_shell 跑
```

## 1. 解析 + 无水印下载
```bash
python3 $SK/scripts/douyin.py info "<用户整段分享文本>"        # 只看信息 (标题/作者/时长/点赞/能否下载)
python3 $SK/scripts/douyin.py download "<用户整段分享文本>"    # 下载, 打印 JSON + 「已保存: 路径 (大小) 时长」
```
- 直接把用户整段分享口令 (含 "复制打开抖音…" 文字) 原样传进去, 脚本自己抠链接、跟随短链。
- 视频取 bit_rate 里分辨率最高的**无水印** play_addr (不是带水印的 download_addr); 图集下载每张原图 (+ 实况图的视频)。
- 高清档有时是 H.265 (hevc), 个别播放器不认时转码: `ffmpeg -i in.mp4 -c:v libx264 -crf 20 -c:a copy out_h264.mp4`。
- **退出码 3 = 作者/平台禁止下载** (例如「作品含AI生成内容暂不可下载」): 尊重设置, 不保存视频,
  如实告诉用户原因; 用户要的是文案就继续走第 2 步 (解读只临时取流, 分析完删除)。不要想办法绕过。
- 交付前验证: 回复里写出 文件路径 / 大小 / 时长 / 分辨率; 需要证明无水印时抽一帧
  `ffmpeg -ss 2 -i 视频 -frames:v 1 check.jpg` 再 `vision_ocr(path=check.jpg, prompt="四个角和画面上有没有抖音 logo/抖音号水印?")`。
- 失败 (exit 2): 作品删除/私密/地区限制。服务器在境外时分享页不可用, 脚本已走境外可用的接口;
  仍失败可让用户提供境内代理, `DOUYIN_PROXY=http://host:port python3 ...`。

## 2. 视频文案解读 (重点)
```bash
python3 $SK/scripts/analyze.py "<分享文本 | 链接 | 本地视频路径>"
```
它会: 取视频 → 抽音频 → ASR 转写口播 → 场景切换抽关键帧 (≤8 张) + 拼图 → 写 `analysis/analysis.json`, 打印下一步。
- ASR 自动选: 本地 faster-whisper (需已缓存模型, 默认没有) → 阿里百炼 `qwen3-asr-flash` (复用 config 里 DashScope 模型的 key) → 都没有则只靠画面字幕。
  转写为空 + note「没识别出人声」= 纯音乐/音效视频, 文案只能看画面字幕和描述, 解读里要说明。
- 然后**一次** `vision_ocr(paths=<analysis.json 的 frames 列表>, prompt=<next_steps 里给的 prompt>)` 识别字幕和画面
  (paths 最多 8 张, 别一张张调)。
- 最后按下面模板输出, 口播全文以 ASR 为准、用画面字幕校对错别字; 两者都没有的部分不要编。
  **解读正文直接写在回复里** (用户要看的就是它), 另存一份 `analysis/解读.md` 并写出路径。

### 解读模板 (输出给用户)
```
## 基本信息   标题/描述 · 作者 · 时长 · 点赞/评论/收藏/转发 · 话题 · BGM
## 口播文案全文   (分段, 标出时间; 纯音乐视频写"无口播", 改列画面字幕/花字)
## 结构拆解   钩子(前3秒说了什么/画面是什么, 为什么能留人) → 铺垫/卖点(逐条) → 转折/反差 → 高潮/金句 → 行动号召(关注/评论/购买引导)
## 爆点分析   情绪点 · 反差点 · 共鸣人群 · 节奏(镜头数/切换频率) · 字幕与画面配合 · 评论区可能的争议点
## 可复用文案模板   把结构抽象成填空模板 (如「[身份]+[反常识结论]，3个原因：①…②…③…，最后一个最扎心」) + 用同一模板改写 1 条示例
```
用户接着要「改写成新文案并做成配音视频」→ 转 video-studio (timeline.json, 画面可直接用 analysis/frames)。

## 3. 本地视频/图片去水印
抖音作品**优先用第 1 步拿无水印原片**; 只有用户给的是本地带水印文件时才用:
```bash
python3 $SK/scripts/dewatermark.py probe 视频.mp4      # 4 帧叠坐标网格 + 左上/右下角按时间平铺条 corner_tl/br.jpg
#   → vision_ocr(paths=[probe 帧 + corner 条]) 读出水印框 x,y,w,h, 以及水印在第几秒换位置
python3 $SK/scripts/dewatermark.py run 视频.mp4 -o 输出.mp4 --box 10,20,245,155@0-5.1 --box 455,1100,260,170@4.9-17 --trim-end 3
python3 $SK/scripts/dewatermark.py run 图片.jpg --box x,y,w,h
```
- 抖音带水印下载的视频: 水印先在左上、约 30% 处跳到右下 (`--preset douyin` 是经验框, 先 probe 核对);
  片尾多 2~3 秒「抖音号」片尾卡, 用 `--trim-end` 去掉。
- 跑完再 probe 输出文件, vision_ocr 复核水印是否消失。
- **局限必须告诉用户**: delogo 是用周边像素插值, 纯色/天空上几乎看不出, 复杂纹理/人脸上会留模糊块;
  半透明满屏水印、跟随运动的水印处理不了 (需要 LaMa/ProPainter 类 AI 修复, 当前未内置)。
- 合规: 只处理用户自己的或已获授权的素材; **不去除「AI 生成」标识** (国家《人工智能生成合成内容标识办法》禁止删除), 遇到就保留并说明。
