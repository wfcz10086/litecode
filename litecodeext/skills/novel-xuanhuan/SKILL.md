# 玄幻题材写作规范

## 核心爽点
- 废柴/被欺压 → 觉醒金手指 → 打脸 → 家族崛起 → 大陆闻名 → 最终称尊
- 每 2000-3000 字一个"爽点小高潮" (打脸 / 突破境界 / 得宝)
- 每 5-10 章一个大高潮 (家族冲突 / 宗门大比 / 跨大陆)

## 典型境界体系 (举例, 可换皮)
```
练气一段 → 练气九段 → 聚气境 → 御气境 → 宗师境 → 帝尊境 → 圣者 → 神帝
```
- **每个境界内部分 9 小阶**, 小阶之间用 "低阶/中阶/高阶/巅峰" 划分
- **大境界之间有"瓶颈"**, 突破需外力 (丹药/秘宝/顿悟)
- 境界名前后 20 章必须完全一致, 不能改口

## 人物配置
- 主角: 家族嫡子但被欺压 / 遗孤 / 穿越者 (二选一, 不要混)
- 核心团队 3-5 人: 大哥/兄弟/红颜/忠仆
- 长辈: 1 位真心对主角好的爷爷/叔叔 (重要情感锚点)
- 反派: 层级递进 - 家族纨绔 → 其他家族老大 → 宗门天才 → 大陆强者
  - 每个反派有 3-5 章戏份, 不要一章就写死
- 红颜: 3-5 位, 人设差异化 (冷艳 / 傲娇 / 温柔 / 天真 / 御姐)

## 金手指设计
常见不踩雷:
- ✅ 灵魂重生 + 上辈子记忆 + 特殊功法/心法
- ✅ 天生异瞳/奇脉 (如紫瞳/雷灵根)
- ✅ 神秘戒指/吊坠藏空间或老爷爷
- ✅ 修炼速度是常人 N 倍 (N 随剧情膨胀)

代价规范 (不加就崩):
- 修炼消耗家底 (灵石/丹药) — 逼主角出去打怪刷钱
- 突破有反噬 (伤身/引天劫)
- 强敌封印金手指 (制造危机)

## 套话黑名单 (本题材尤其高发)
- "境界如此之低, 怎么可能有这种修为"
- "区区 XX 境, 也敢在本少爷面前放肆"
- "你这是什么功法, 居然能 XXX"
- "不可能, 绝对不可能"
- "就凭你?"
- "此子不除, 必成大患"
- "少年, 你成功引起了我的注意"
- "想不到此人如此年轻, 竟有如此修为"

> 上述句式**每 3000 字最多 1 次**, 超过就重写。

## 章节结构模板 (每章 3000 字)
```
开头 (300字)  : 场景切入 / 冲突引入 (悬念, 不要"话说")
  ↓
展开 (1500字): 主角行动 / 对话推进 / 小高潮铺垫
  ↓
高潮 (800字) : 打脸 / 突破 / 揭秘 (本章爽点)
  ↓
收尾 (400字) : 情绪落地 / 下章钩子 (禁"欲知后事如何")
```

## 世界观必备字段 (world_bible.md)
```yaml
dimension:      # 空间层次
  - 小世界 → 下界 → 中界 → 上界 → 神界
  - 具体每界由哪些大陆组成
races:          # 种族
  - 人族 / 魔族 / 妖族 / 精灵族 / 龙族 (选 3-5 个用)
clans:          # 势力
  - 8 大家族 / 3 大宗门 / 1 个神秘组织
artifacts:      # 核心宝物
  - 不超过 5 件, 每件有明确属性和来历
laws:           # 天道/规则 (如"渡劫必须独自面对")
```

## 禁忌
- ❌ 用修真术语 (不能有"炼气/筑基/金丹/元婴"; 那是 novel-xiuzhen)
- ❌ 用武侠术语 (不能有"内力/真气/点穴"; 那是 novel-wuxia)
- ❌ 境界跳跃 (不能 A 章练气, B 章直接宗师, 必须循序渐进)
- ❌ 一章内 > 3 次"突破" (剧情水)
- ❌ 反派降智 (主角打反派要靠智谋+实力, 不是对方突然犯傻)
