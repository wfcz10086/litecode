# 穿越题材写作规范

## 核心机制 (选其一)
```
A. 身穿: 整个人穿过去 (最常见, 会有"如何解释 10 分钟前 X 事"的麻烦)
B. 魂穿: 附身原主, 继承记忆 (相对好写, 没身份问题)
C. 穿书: 穿到小说里 (知道剧情是金手指, 但会"剧情修正力")
D. 穿游戏: 穿到游戏世界 (有 UI / 等级)
E. 穿动漫: 成为角色 (比穿书更细致)
F. 双穿: 两个世界来回 (自由度最大, 但设定最复杂)
```
**选定后全书不能切换机制**.

## 穿越者"常见错误" (避免)
- ❌ **语言无障碍**: 古人说文言, 现代人听懂? 要给解释 (如"系统翻译/灵魂感应")
- ❌ **生活习惯完美适应**: 古代没空调没抽水马桶, 主角 3 章就适应? 假
- ❌ **现代知识全能**: 一个文科生全懂工业革命 → 解释"为什么这个文科生刚好懂这些"
- ❌ **不暴露身份就暴露知识**: 开口就"量子力学 / 相对论", 古人当场疯

## 现代知识金手指 (合理范围)
```
基础物理: 杠杆 / 滑轮 / 水车 — 能造
初级化学: 肥皂 / 盐 / 火药 — 能造 (火药后果严重, 慎用)
军事: 阵法 / 马镫 / 弓弩改良 — 可
管理学: 薪酬制 / 考核 / 销售话术 — 可
医学: 消毒 / 青霉素 — 谨慎 (实现成本高)
高阶: 内燃机 / 电池 / 半导体 — 工业基础不允许
```

## 身份适应节奏 (前 10 章)
```
Ch1: 穿越发生, 搞清楚时空
Ch2: 认识周围人 (原主家人/朋友)
Ch3-4: 第一次尝试用现代知识帮人 / 赚钱
Ch5-7: 小成功 + 小挫折 (被怀疑)
Ch8-10: 站稳脚跟, 有了目标
```

## 叠加题材 (配合其他 skill)
- 穿 + 古代 → `load_skill novel-lishi`
- 穿 + 玄幻 → `load_skill novel-xuanhuan`
- 穿 + 修仙 → `load_skill novel-xiuzhen`
- 穿 + 都市 → 其实就是重生, `load_skill novel-zhongsheng`

## ⚠️ 强制搜索 (穿古代)
- 朝代 / 年号 / 皇帝
- 物价 (银两 / 粮食 / 衣物)
- 官制 / 科举 / 军制
- 礼仪 (称呼 / 下跪 / 避讳)
- 地理 (古地名)

## 套话黑名单
- "21 世纪穿越者"
- "老子穿越来的"
- "想不到我居然穿越了"  (开局用 1 次即可)
- "凭借我的现代知识"
- "在古代当咸鱼"
- "这个时代的人果然不懂"

## 禁忌
- ❌ 主角看谁都鄙视 (傲慢人设讨厌)
- ❌ 女主穿越必嫁王爷 (套路太滥)
- ❌ 改变大历史 (除非是架空)
- ❌ 同时多个穿越者 (稀释金手指, 容易混乱)
- ❌ 穿越后身体素质异常 (一个废柴突然武功盖世, 没逻辑)
