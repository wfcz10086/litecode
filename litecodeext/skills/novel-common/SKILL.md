# 所有小说通用: 红线 + 常见坑 + 边写边查触发清单

> 本 skill 专门收录 **跨题材共性问题**. 21 个题材 skill 只写本题材专属。

## 写前必做 (3 条铁律, 不做不准动笔)

1. **load_skill novel-common** (本 skill, 通用规则)
2. **load_skill novel-{题材}** (具体题材规则, 如 novel-xuanhuan)
3. **read_file story_state.json** 或 **read_file PROJECT_BOARD.md** (不写进度则停笔)

## 通用"常见坑" (9 个大类, 实测读者最反感)

### 1. 开局杀手
- ❌ 第一章塞 500+ 字世界观 — 读者劝退 #1 原因
- ❌ 第一段全是心理活动 — 要动作 / 对话 / 环境开头
- ❌ 第一章就把金手指全展示 — 后续失去期待
- ✅ **正确**: 用一场"冲突 / 悬念 / 动作" 把读者拽入世界

### 2. 主角设定崩
- ❌ 龙傲天: 从头到尾不输不挣扎 — 读者腻
- ❌ 毫无缺点完人: 再聪明也要有性格缺陷 (多疑 / 贪财 / 优柔)
- ❌ 金手指秒杀一切 — 必须有代价 / 限制 / 反噬
- ❌ 毫无成长: 第 100 章还是第 1 章的心智
- ✅ **正确**: 每 20-30 章让主角"吃一次亏" (非死劫), 推动成长

### 3. 反派降智
- ❌ 反派纯坏无理由
- ❌ 反派智商掉线 ("主角打我左脸? 我再给你右脸!")
- ❌ 反派临死自白动机 (都要死了还啰嗦)
- ✅ **正确**: 反派有自己的逻辑, 和主角是"对手而非供品"

### 4. 女性角色处理
- ❌ 全"冷艳倾国"无差异
- ❌ 女性只等救 / 只当奖励
- ❌ 女角互相拉踩 (恶毒女配模板)
- ❌ 软色情堆砌 (读者会翻白眼)
- ✅ **正确**: 至少 1 位有独立故事线的女性, 不是只围绕男主转

### 5. 时间线 / 细节崩
- ❌ 前 10 章说主角 16 岁, 后 5 章变成 18 岁却没有说明
- ❌ 武功 / 技能忘记设定 (A 章说是火系, B 章用冰)
- ❌ 地名前后不一 ("青云宗" 和 "青云门" 混用)
- ❌ 出场角色数量爆炸但没档案 (50 章后读者记不住)
- ✅ **正确**: 用 characters.db + timeline.md 强制一致性

### 6. 对话全是台词
- ❌ 连续 500 字只有 "A 说 / B 说" 没动作没环境
- ❌ 对话全是"功能性"(推剧情), 没有闲笔 / 性格体现
- ❌ 所有角色语气一个样
- ✅ **正确**: 每场对话混入 30-40% 场景 / 动作 / 内心戏

### 7. 节奏崩
- ❌ 水字数: 一章 3000 字只讲一个动作
- ❌ 压缩太快: 一章跳过半年, 读者断片
- ❌ 爽点全集中 (一章 5 个反转) 或全无 (10 章平铺)
- ✅ **正确**: 每章 ≥ 1 个推进点, 每 5 章一个大事件

### 8. 世界观漏洞
- ❌ 规则说一套做一套 (说"御剑飞行耗元气"但主角满篇飞)
- ❌ 地图设定不写, 角色"瞬间"到任何地方
- ❌ 经济荒谬 (古代主角动辄"千两黄金")
- ✅ **正确**: world_bible.md 一次写定, 违反设定就重写

### 9. 结尾雷
- ❌ 烂尾 (最后几章草草收场, 伏笔未兑)
- ❌ 大团圆强行 (前面虐完了突然 happy ending)
- ❌ 开放结局不铺垫 (读者一脸问号)
- ❌ 作者上场 (突然写 "读者你好, 这个故事...")
- ✅ **正确**: 前 20 章就想好结尾, 反推伏笔

## 边写边查: 必搜触发清单 (writer 看到就停笔查)

### 🔴 高优先级 (不搜必出错)

1. **任何 4 位数真实年份**
   - 例: "2024 年", "公元 208 年"
   - 除非已在 world_bible 明确是架空

2. **真实人物姓名**
   - 演员 / 作家 / 历史人物 / 企业家
   - ⚠️ 慎写, 可能涉及法律风险, 尽量化名

3. **真实公司 / 品牌 / APP**
   - "苹果 / 华为 / 拼多多 / 抖音"
   - 不仅查存在, 还要查它在故事时间点的状态

4. **技术术语定义**
   - "量子 / AI / 区块链 / CRISPR" 等
   - 武侠里的"气功 / 内劲" 要查真实武术文献

5. **真实地名 / 地标**
   - "北京三里屯 / 长安大慈恩寺"
   - 年代不对的地名会出错

### 🟡 中优先级 (可以先写, 事后核实)

6. **影视 / 小说 / 游戏引用**
   - 必须是已发行 + 剧情准确
   - 引用台词要完整不错字

7. **数字事实**
   - 股票 / 房价 / 人口 / 面积
   - "上海人口 2500 万" 要有来源

8. **专业细节**
   - 医学: "心脏骤停 10 分钟" (真实 4-6 分钟)
   - 法律: "杀人必死刑" (错)
   - 金融: "做空" / "杠杆" 要懂再写

### 🟢 低优先级 (凭合理推理即可, 但要标注)

9. **历史 / 文化常识**
   - 可以先写, 事后抽查
   - 出错会被读者骂但不致命

10. **武器 / 兵器细节**
    - 枪支型号 / 冷兵器样式

## 搜到之后怎么处理

```
✅ 有权威来源 (政府 / 机构 / 论文):
   写进正文, data.json 记录 url + 访问时间
✅ 只有媒体 / 博客来源:
   写进正文, 但标注"据 XX 报道", 不下绝对论断
✅ 多来源矛盾:
   取权威优先, 或写成"众说纷纭, 有 A 说 B 说"
⚠️ 搜不到权威来源:
   标 [数据 TBD] 或 [此处存疑], 继续写
❌ 搜不到还硬写:
   禁止. 宁可换情节也不能编
```

## 每章写完自检清单 (execute_shell 跑)

```bash
# 1. 字数 (中文)
python3 -c "import re,sys; t=open(sys.argv[1]).read(); print(f'中文: {len(re.findall(chr(0x4e)+r\"..-.\"+chr(0x9f)+r\"ff\", t))}')"
# 实际用:
python3 -c "import re; t=open('chapter_01.md').read(); cn=len(re.findall(r'[\u4e00-\u9fff]',t)); print(f'中文字数: {cn}')"

# 2. AI 味自审 (如 load 了 anti-ai-tell-audit)
python3 ai_tell_audit.py chapter_NN.md --report audit_NN.md
# 退出码非 0 → 按 audit_NN.md 建议重写

# 3. 时间线 / 角色档案一致性
sqlite3 characters.db "SELECT name, last_chapter FROM characters ORDER BY last_chapter DESC"
# 看新一章是否漏登记角色

# 4. 引用核验 (报告类必做)
grep -E '\[source:|据.*报道|\(\d{4}\)' chapter_NN.md | wc -l
# 每 500 字 ≥ 1 条引用才合格
```

## 生成长文的 DO / DONT 总结

| DO | DONT |
|---|---|
| 先 load_skill novel-common + novel-{题材} | 不看 skill 直接写 |
| 写前 read story_state.json | 凭记忆写 |
| 每章 ≤ 4000 字 | 一次塞 10000 字 |
| 写完立刻 update 档案 | 写完忘了状态 |
| 搜索加 [source:] | 编造数据 |
| critic 说不合格就重写 | 忽视 critic 建议 |
| 每 10 章 l2_summary 压缩 | 靠 L1 硬塞全文记忆 |
| 用具象细节 (他的帆布鞋沾着泥) | 用空洞形容 (他很狼狈) |
