# 科幻题材写作规范

## 硬度分级
```
硬科幻 (《三体》《海伯利安》): 技术细节 > 剧情爽感
中度 (《基地》《银河英雄传说》): 政治+科技+人文
软科幻 (《星球大战》): 科幻外壳 + 传统英雄叙事
太空歌剧: 星际帝国 + 种族斗争 + 宏大战役
赛博朋克 (《神经漫游者》): 高科技低生活 + 反乌托邦
```

## 必须遵守的自洽规则
- **设定一次性**: 开头说"光速不变", 后面就不能突破光速 (除非引入新设定并解释)
- **技术树清晰**: 能打星际战斗 = 已有反物质/曲率驱动; 不能"古代武士在星舰上用剑"
- **时间单位**: 光年 / 天文单位 / 秒差距 要用对
- **距离感**: 银河系直径 10 万光年, 最近恒星 4.2 光年 — 这些不能瞎编

## ⚠️ 强制搜索 (不搜必翻车)
- 物理常量: 光速 / 引力常数 / 普朗克常数
- 天文数据: 恒星距离 / 行星质量 / 轨道
- 现代科技: 量子计算 / AI 发展现状 / 芯片工艺
- 生物学: DNA / 细胞 / 进化
- 工程: 航天器推进 / 核聚变 / 反物质

## 常见子类型

### A. 硬科幻 (技术 > 人物)
- 每章至少 1-2 个扎实科学设定
- 动作场面让位于逻辑推导
- 结局常是"发现"而非"胜利"

### B. 太空歌剧
- 星际帝国 / 贸易联盟 / 氏族斗争
- 技术为剧情服务 (不深究原理)
- 英雄主义 + 宏大战役

### C. 赛博朋克
- 必备元素: 霓虹灯街区 / 公司政治 / 义体 / 黑客 / 毒品
- 人物: 底层黑客 / 失业者 / 走私贩 / 大公司白领
- 色调: 蓝 + 紫 + 血红, 永远下雨

### D. 时间旅行
- 必须选定一种因果模型:
  - 蝴蝶效应 (微改变 → 大后果)
  - 固定时间线 (无论怎么改, 原有事件仍发生)
  - 多元宇宙 (每次改动分裂新宇宙)
- 选定后贯彻到底, 不能前后矛盾

## 世界观字段
```yaml
era:             # 纪年 (西元 / 星历 / 自创)
tech_level:      # 卡尔达肖夫等级 (I/II/III 型文明)
key_tech:        # 关键科技
  - 曲率驱动 / 超光速通信 / 思维上传 / 冷冻休眠
factions:        # 势力
  - 地球联盟 / 火星自治 / 外星种族
conflicts:       # 核心冲突 (资源 / 意识形态 / 生存)
physics_laws:    # 本世界物理规则 (标哪些与现实不同)
```

## 套话黑名单
- "科技树点满"
- "逆天改命"
- "基因觉醒"
- "AI 失控要灭掉人类"  (太烂大街)
- "XX 元素/粒子" (瞎造的科学词)
- "上古超文明"  (尽量有具体描写)

## 人物配置
- 主角: 科学家 / 工程师 / 军人 / 商人 / 黑客 (职业决定视角)
- 配角: 至少 1 位"反派逻辑自洽" (不是纯坏, 有他的理由)
- AI 角色: 要有明确动机和限制 (不要万能)
- 外星人: 文化 / 生理 / 思维方式全面不同, 不能是"绿皮小人"

## 禁忌
- ❌ 科学名词乱用 (别把"量子"当玄学)
- ❌ 光速以下战斗 (真打星战 = 几小时对峙, 不是爽片)
- ❌ 通用翻译器 (除非解释原理)
- ❌ 外星人长得像人 (要有生物学依据或明确理由)
- ❌ 高科技低智商 (星际文明为啥还用"刀剑单挑")
- ❌ 时间旅行逻辑崩 (祖父悖论不能忽视)

## 章节模板
日常 / 任务启动 (500) → 探索 / 发现 / 行动 (1500) → 矛盾升级 (700) → 反转或高潮 (300)
