# 都市题材写作规范

## 核心要点
- **时代感第一**: 必须能标出具体年份 (如 2024 / 2025 / 2026), 涉及真实品牌/APP/热点要精准
- **真实场景感**: 写北京就要用"三环/国贸/CBD", 不能全是虚构"东海市"
- **金手指落到实处**: 异能 / 系统 / 前世记忆 解决的是 真实生活痛点 (买房/考研/失业/相亲)

## ⚠️ 强制搜索规则 (本题材最严)
涉及以下内容**必须 web_search 核实**, 不得凭训练数据编:
- 真实品牌 (苹果/华为/拼多多/美团价格)
- 真实地点 (商场/街道/医院/景点)
- 真实人物 (明星/企业家/政要) — 谨慎用, 法律风险
- 当年热点 (节日/事件/政策)
- 影视剧引用 (必须是已播且准确的剧情/台词)
- 股票 / 加密货币 / 房价数字

**搜了之后来源要标注**: "据 XX 2024-11 报道..."

## 常见子类型 (选一个主线)

### A. 都市重生流
- 重生回 X 年前 (常见 2008 / 2012 / 2015)
- 靠"预知未来"吃红利 (买房/炒股/创业)
- **时间轴必须准**: 2015 年还不能用微信支付吗? (能)
- 知名事件 / 上市公司时间点不能错

### B. 都市兵王/医仙
- 主角退役军人 / 隐世高手 / 祖传中医 入城市
- 低武背景下的"打脸"
- 必有"大隐隐于市"的氛围

### C. 都市异能
- 悄然觉醒超能力 (读心/预知/控物)
- 主线多为破案 / 救灾 / 对抗神秘组织
- 气氛介于都市和玄幻

### D. 商战/职场
- 主角创业 / 打工人逆袭
- **行业细节要真**: 互联网 / 金融 / 地产 / 餐饮
- 不是"随便创个公司就上市"

## 人物配置
- 主角: 有明确职业 (程序员/医生/老师/律师) 不能模糊
- 家庭: 父母俱在 (都市讲家庭责任), 或有兄弟姐妹
- 红颜: 2-3 位 (白领 / 同学 / 邻家 / 客户), 职业各异
- 反派: 职场对手 / 商业敌人 / 渣男女 / 隐藏组织

## 章节模板
生活日常 (500) → 矛盾引入 (800) → 金手指/能力介入 (1000) → 解决 (500) → 新伏笔 (200)

## 套话黑名单
- "我这一辈子必将辉煌"
- "王者归来"
- "人生赢家"
- "不要在我面前装 X"
- "你可知我是谁"
- "**集团 CEO" (太虚)
- "系统提示: 叮~" (除非明确系统流)

## 禁忌
- ❌ 科技细节瞎编 (什么叫"量子芯片" 请搜)
- ❌ 金融术语乱用 (杠杆/做空/对冲要懂再写)
- ❌ 法律常识错误 (杀人不判死刑? 股票内幕交易没事?)
- ❌ 医学常识错误 (心脏骤停不是捶几下就好)
- ❌ 真实明星隐私/绯闻 (改名化吧)
- ❌ 地域黑 / 职业黑 (容易翻车)
