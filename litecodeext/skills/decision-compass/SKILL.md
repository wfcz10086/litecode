# 决策罗盘

目标: 让人从"一团乱麻的纠结"变成"知道自己在赌什么、凭什么赌、错了怎么办"。
**不替用户做价值判断**; 替用户把事实、假设、选项、代价摆清楚。

## 第 0 步: 先问清 4 件事 (缺哪个问哪个, 一次最多问 3 个)

| 问题 | 为什么要问 |
|---|---|
| 1. 到底要决定什么? 用一句"是否/选哪个/何时"的问句写出来 | 一半的纠结来自问题本身没定义 |
| 2. 什么时候必须决定? 拖着不决定的代价是什么? | 区分"真紧急"和"焦虑感" |
| 3. 有哪些选项? (至少 3 个, 包括"维持现状"和"先小规模试") | 只有二选一时, 通常漏了选项 |
| 4. 你最在乎什么? 最怕什么? | 价值排序决定权重, 不能由 AI 代填 |

## 第 1 步: 决策定型

先判断类型, 不同类型用力程度完全不同:

| 维度 | A 档 | B 档 |
|---|---|---|
| 可逆性 | **双向门**: 做错能低成本撤回 → 快决定, 先试 | **单向门**: 撤不回/代价极高 → 慢决定, 全流程 |
| 卡点 | 事实不清 (缺信息) | 价值冲突 (信息够了, 是取舍难) |
| 风险形态 | 损失有上限 | 有尾部风险 (破产/健康/名誉/法律) |

规则:
- 双向门 + 损失有上限 → 只做第 2 步的"最小检查", 建议直接选一个先试, 设好止损点。
- 单向门 或 有尾部风险 → 走完整流程, 至少用 3 个工具。
- 卡在"事实不清" → 先列"要查清的 3 个事实 + 怎么查 + 查到什么会改变决定", 别急着打分。
- 卡在"价值冲突" → 用决策矩阵把权重摆上桌, 让用户自己调权重看结论是否翻转。

## 第 2 步: 选工具 (按卡点对号入座)

| 症状 | 用哪个技能 |
|---|---|
| "大家都这么做"、思路被行业惯例框住 | `first-principles` 第一性原理拆解 |
| 多个选项、多个标准, 比来比去比不清 | `decision-matrix` 加权决策矩阵 (带灵敏度分析脚本) |
| 已经倾向某个方案, 想知道会怎么死 | `premortem` 事前验尸 |
| 很确定、很兴奋、身边没人唱反调 | `red-team` 反方论证 / 红队 |
| 眼前收益明显, 但担心后劲 | `second-order-thinking` 二阶后果推演 |
| 判断里有"大概率""应该会""十有八九" | `calibrated-forecast` 概率与基础比率校准 |
| 情绪重、已投入很多、怕丢面子 | `bias-check` 认知偏差检查 |
| 不是选哪个, 而是事情太多先做哪个 | `priority-triage` 优先级分诊 |
| 事情已经做完/搞砸了, 想吸取教训 | `after-action-review` 复盘 |

用 `load_skill` 读对应技能全文再执行, 不要凭印象简化。

**最小检查** (双向门也要做, 5 分钟):
1. 这个决定最坏结果是什么? 我扛得住吗?
2. 有没有一个更便宜的方式先试 (租代买 / 兼职代辞职 / 小样本代全量)?
3. 什么信号出现时我会停下或反悔? (写成具体数字或事件)

## 第 3 步: 输出一页决策备忘 (固定模板)

```markdown
# 决策备忘: <一句话问题>
日期: YYYY-MM-DD   必须决定的时间: ____   类型: 双向门/单向门, 事实不清/价值冲突

## 1. 已知事实 (有出处或可核实)
- ...
## 2. 关键假设 (没核实但决定依赖它)
| 假设 | 若为假, 结论会变吗 | 怎么最便宜地验证 | 期限 |
## 3. 未知且无法短期查清的
- ...
## 4. 选项对比 (含"维持现状"和"小试")
| 选项 | 最好情况 | 最可能情况 | 最坏情况 | 可逆性 |
## 5. 建议 (标注把握度: 高/中/低, 并写理由)
- 倾向: ____ , 把握度 __ , 因为 ____
- 什么情况下这个建议会错: ____
## 6. 止损/复查点
- 若 <具体信号> 出现, 则 <具体动作>
- 复查日期: ____ (到时用 after-action-review 复盘)
```

## 纪律

- 事实、假设、观点三者分栏写, **不许混在一段话里**。
- 每个"大概率"后面跟一个数字 (如 70%) 和依据; 没依据就写"凭感觉"。
- 用户说"你直接告诉我选哪个"时: 可以给倾向, 但必须同时给出"什么情况下我会改主意"。
- 涉及医疗、法律、大额投资时, 写明"本分析不替代持证专业人士意见", 并列出该问专业人士的 3 个具体问题。
- 结尾不要鸡汤, 以"下一步 (今天就能做的 1 件事)"收尾。
