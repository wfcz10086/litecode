# 重生题材写作规范

## 核心机制
- **前世有明确遗憾** (失业 / 背叛 / 亲人去世 / 没赚到钱)
- **重生后的使命**: 修复遗憾 + 利用时代红利
- **金手指**: 前世记忆 + 未来知识 (股票 / 房价 / 科技 / 人物起落)

## ⚠️ 强制搜索 (本题材最严)
每涉及一个真实年份事件都要 web_search:
- 经济: 股票走势 / 房价 / 重要公司上市时间
- 科技: iPhone / 微信 / 抖音 / 各大 APP 发布时间
- 社会: 奥运 / 疫情 / 政策变化
- 影视娱乐: 歌曲 / 电影 / 电视剧发布
- 真实人物起落 (商业明星 / 演员)

**时间线错误 = 读者秒弃**.

## 常见起点年份 & 时代红利
```
1998: 互联网起步 / 股权激励
2003: 非典带机遇 (网购 / 健身)
2008: 奥运经济 / 房价起飞 / 腾讯股价
2012: 智能手机普及 / 微博热 / 手游黄金期
2015: 创业潮 / 股灾 / 直播起步
2018: 抖音崛起 / 5G / AI 产业
2020: 疫情 / 新能源车 / 直播带货
```

## 前世失败模板 (选一个)
```
A. 被兄弟/好友背叛, 公司被夺
B. 被渣男/渣女骗, 婚姻失败
C. 错过上车股票 / 房子的时机
D. 家人因病无钱治疗去世
E. 考试失利 / 选错专业
F. 被冤枉入狱
```

## 爽点设计
- **第一章重生瞬间**: 对比前世惨状, 情绪爆发
- **第二章开始布局**: 关键人物 / 关键交易
- **打脸前世仇人**: 10-15 章有第一次打脸
- **吃时代红利**: 20-30 章有第一桶金

## 人物配置
- 主角: 有明确前世身份 (程序员 / 医生 / 职员), 决定使用的知识面
- 前世仇人: 2-3 位, 要有前因后果 (不是单纯坏)
- 红颜: 前世错过 / 前世亏欠 的女性 (通常是老婆 / 初恋)
- 家人: 父母健在, 弥补前世"子欲养而亲不待"

## 章节模板
当下场景 (500) → 前世对比 / 回忆 (400) → 用未来知识行动 (1200) → 眼前收益 (600) → 下步谋划 (300)

## 套话黑名单
- "给老子等着" (太烂大街)
- "这一世我要"  (开头用 1 次就够)
- "重活一世"
- "上天又给了我一次机会"
- "前世今生"
- "还是原来的配方"

## 禁忌
- ❌ **时间线错误** (说 2010 年用微信 — 微信 2011 年才出)
- ❌ 太顺利 (重生 = 金手指已够强, 再给空间/系统, 就过了)
- ❌ 反派前世就是纸片人 (要有让主角失败的现实逻辑)
- ❌ 知识点错误 (不会写的行业就搜, 不要编)
- ❌ 忽略"蝴蝶效应" (主角改一件事, 后续未来不该还是原样)

## 世界观字段
```yaml
rebirth_year:      # 重生的起点年份
rebirth_season:    # 月份 / 季节
past_life_end:     # 前世死 / 挫败 的年份
past_memory:       # 前世大事件时间轴 (主角知道的)
key_companies:     # 关键公司 (上市时间 / 股价变化)
key_people:        # 关键人物 (知名企业家 / 明星, 化名处理)
key_events:        # 社会大事
divergence_points: # 关键蝴蝶点 (主角已改变的事件)
```
