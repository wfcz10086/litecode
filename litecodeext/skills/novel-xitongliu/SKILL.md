# 系统流写作规范

## 核心 — 系统流独有的"三要素"
- **系统人格**: 冷漠机械 / 腹黑智能 / 傲娇 / 萌系 — 必须选定一种
- **规则清晰**: 任务触发 / 奖励兑换 / 惩罚机制 写清楚
- **成长可量化**: 等级 / 经验值 / 积分 (数字党爱好)

## 系统人格设定 (选其一)
```
A. 机械冷漠型: "宿主, 任务下发." "违规, 扣除 100 积分."
B. 腹黑主系型: 常耍宿主玩, 有小心思 (如"淘宝系统")
C. 萌萌乖巧型: "宿主大大, 这次任务给你准备了超棒的奖励哦~"
D. 反派逼迫型: 威胁型系统 ("不完成就消除你")
E. 沙雕搞笑型: 瞎出任务, 比如"娶老板娘"
```

## 系统接口规范 (必写清)
```
任务: 触发条件 + 奖励 + 惩罚 + 时限
  例: 【签到任务】每日登录 → 奖励 100 积分 → 断签 3 日扣除称号

等级: 有明确升级条件
  例: Lv1 → Lv2 需要 1000 经验

商城: 奖励梯度
  D 级 (100 积分): 日常用品 / 基础技能
  C 级 (1000 积分): 稀有物品
  B 级 (10000 积分): 跨阶奇物
  A 级 (100000 积分): 改变世界

隐藏机制:
  - 连续签到奖励
  - 等级跃升福利
  - 世界 / 身份 / 任务类型差异
```

## 叠加主题
- **系统 × 玄幻** → 境界对应系统等级
- **系统 × 都市** → 任务是现实生活挑战
- **系统 × 末世** → 杀敌 / 救人 赚积分
- **系统 × 历史** → 改变历史轨迹换积分
- **系统 × 种田** → 种地 / 盖房 触发任务

**注意**: 选叠加类型后, 同时参考对应题材 skill (如 `load_skill novel-xuanhuan`)

## 爽点公式
```
触发条件 (铺垫) → 系统介入 (惊喜) → 奖励到手 (满足)

每 500-800 字一次系统反馈 (超高爽点密度)
```

## 套话黑名单
- "叮~ 系统提示"  (用 1-2 次, 不能全章都叮)
- "恭喜宿主完成任务" (换点花样)
- "奖励发放中"
- "金手指到手"
- "爽快不已"
- "主角笑道: 真香"

## 禁忌
- ❌ 系统万能 (什么都能做, 读者无代入感)
- ❌ 系统 bug 就改规则 (主角卡 bug 情节可 1-2 次, 不能天天卡)
- ❌ 系统人格前后矛盾 (一会儿冷漠一会儿萌)
- ❌ 奖励通胀 (后期奖励几千亿积分, 没价值感)
- ❌ 忘记系统存在 (几十章不提系统 = 人设崩塌)

## 章节模板
日常 (500) → 任务触发 (400) → 主角行动 (1200) → 系统结算 (500) → 新任务引入 (400)
