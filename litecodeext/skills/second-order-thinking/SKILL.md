# 二阶后果推演

一阶思维: "降价 → 销量涨"。
二阶思维: "降价 → 销量涨 → 对手跟进降价 → 全行业利润降 → 用户形成等降价预期 → 原价卖不动"。
本技能的任务是把"然后呢?"系统地问到第三层, 并找出真正要盯的指标。

## 第 1 步: 写清动作和预期的一阶效果

```
动作: ____ (谁, 在什么时候, 做什么)
预期一阶效果: ____ (为什么要做它)
```

## 第 2 步: 列利益相关方 (至少 5 个)

自己 / 直接对象 (用户、员工、家人) / 竞争者 / 合作方与供应商 / 监管或平台 / 旁观者与舆论 / 未来的自己。
每方写一句: **他们的激励是什么? 这个动作改变了他们的什么?**

## 第 3 步: 后果树 (每方问 3 次"然后呢")

```
动作
├─ 相关方A: 一阶 → 二阶 → 三阶
├─ 相关方B: 一阶 → 二阶 → 三阶
└─ ...
```

每个节点标注: 可能性 (高/中/低)、方向 (+/-)、是否可逆。
不要只写坏的: 也找**意外的好处**。

## 第 4 步: 时间尺度对照 (10/10/10)

| 时间 | 我方得失 | 关键相关方的反应 | 局面 |
|---|---|---|---|
| 10 天后 | | | |
| 10 个月后 | | | |
| 10 年后 | | | |

常见模式: 短期好、长期坏 (透支、债务、信任损耗); 短期痛、长期好 (投资、学习、修复)。
**明确写出这个决定属于哪种模式。**

## 第 5 步: 找结构性问题 (逐条检查)

- [ ] **反馈回路**: 有没有自我强化 (越来越好/越来越坏) 或自我抵消的循环? 画出来: A↑ → B↑ → A↑
- [ ] **激励扭曲**: 考核指标会不会被"刷"? (古德哈特定律: 指标一旦成为目标就不再是好指标)
- [ ] **对手适应**: 别人学会/跟进之后, 优势还在吗?
- [ ] **不可逆点**: 哪一步做了就回不去? (裁员、公开承诺、品牌受损、关系破裂)
- [ ] **先例效应**: 这次这么做, 以后类似情况会被要求同样处理吗?
- [ ] **累积效应**: 单次无害, 重复 100 次呢?
- [ ] **眼不见**: 成本是不是转移给了看不见的人或未来的自己?

## 第 6 步: 结论与监测

```markdown
## 推演结论
- 一阶效果: ____ (把握: 高/中/低)
- 最重要的二阶后果: ____ (正/负, 多久后显现)
- 最大的隐藏风险: ____
- 属于: 短期好长期坏 / 短期痛长期好 / 两头都好 / 两头都坏
## 调整建议 (怎样保留一阶收益、削弱二阶负面)
## 监测指标 (先行指标, 带阈值和检查时间)
| 指标 | 现在 | 警戒线 | 多久看一次 | 越线后动作 |
```

## 纪律

- 推演是**假设**不是预言, 每条注明把握度; 能用历史类似案例佐证的, 用 web_search 找 1~2 个, 并注明出处。
- 推到三阶就够了, 再往后不确定性太大, 写"以后不确定"即可, 不要编故事。
