# AI 写歌 (带人声 + 歌词)

> ⭐ **这是固定流程, 别绕路**: 要人声 / 歌词 / "唱" 就用本技能; **不要**用 bgm-music 的本地合成器交差 (它只能出纯音乐)。
> 服务是「能力接入」里的音乐卡 **ACE-Step 1.5** (开源 MIT, 跑在 gpu-a, 2 分钟的歌约 1 分钟出)。脚本自动找卡, 不用手写 curl。

```bash
SG="python3 ${LITECODE_HOME:-/opt/litecode}/skills/ai-song/scripts/song.py"
OUT=/tmp/litecode_workspace/music
$SG status                                   # 服务在不在线、用的哪张卡、能不能核对唱词
```

## 流程 (按顺序)

1. **定歌**: 从用户的话里抓 4 件事, 没说的自己按常理定, 不要反问: 主题情绪 · 曲风 (+BPM) · 男声/女声 · 时长 (默认 90 秒; "DJ / 蹦迪" 默认 128 BPM 电子舞曲)。
2. **写歌词** 存成文件 `$OUT/<歌名>_歌词.txt`, 用段落标签分段 (标签单独一行):
   ```
   [verse]       主歌 4 行
   [pre-chorus]  导歌 2 行 (可选)
   [chorus]      副歌 4 行, 最抓耳, 后面重复
   [verse] / [chorus] / [bridge] 2~4 行 / [chorus] / [outro]
   ```
   - **行数要和时长、速度对上** (否则模型会拉长前奏、跳过主歌): 慢歌 (≤85 BPM) 每句约 4 秒, 中快歌约 3 秒, 再留 6 秒前奏 / 尾奏。
     例: 40 秒慢歌 ≈ 8 句, 40 秒快歌 ≈ 11 句; 写多了就加时长或删词。
   - 每行 6~12 个字, 押韵, 副歌一句能当标题; 90 秒约 16~24 行, 120 秒约 24~32 行。**时长默认 ≤ 150 秒**, 用户没要求长歌就别写到 60 行以上 (越长越慢, 4 分钟以上的歌容易超时)。
   - 别写说明文字、括号注释、表情符号 (会被唱出来)。
3. **生成**:
   ```bash
   $SG gen --prompt "失恋但很嗨的电子舞曲, EDM, DJ, 128 BPM, 强劲四拍底鼓, 合成器主旋律, 女声主唱" \
       --lyrics-file "$OUT/失恋DJ_歌词.txt" --duration 120 --bpm 128 -o "$OUT/失恋DJ.mp3" --verify
   ```
   - `--prompt` 写曲风 + 情绪 + 主要乐器 + 速度 + 人声性别, 用逗号分开。
   - 常用曲风写法:
     - 古风 / 空灵 (类《青衣》那种): `古风, 中国风, 古筝, 竹笛, 琵琶, 空灵女声, 气声, 大混响, 慢板 72 BPM, 宫调五声音阶, 孤寂`
     - 民谣: `民谣, 木吉他, 口琴, 温暖男声, 90 BPM` · 说唱: `中文说唱, trap, 808 鼓, 男声 flow, 140 BPM`
     - 只拿歌名 / 歌手当**风格参照**, 不要在 prompt 里写真实歌手名, 也不要模仿某人的嗓音。
   - 英文歌 `--lang en`, 粤语 `--lang yue`; 纯音乐加 `--instrumental` (不用写歌词)。
   - 想要几个版本挑: 换 `--seed` 多跑几次, 文件名加 A/B。
4. **核对**: `--verify` 会把前 60 秒转成文字 (输出 "识别到的唱词")。大体对得上歌词就算过 (个别错字是识别误差);
   完全对不上或只有前奏, 就把时长加长或换 seed 重出一次。
5. **交付**: 回复里写 mp3 路径 (网页出播放卡片) + 完整歌词 + 曲风/BPM/时长; 注明 "AI 生成 (ACE-Step 1.5, MIT 许可)"。

## 出错怎么办
- `能力接入里没有可用的 AI 作曲卡` → 告诉用户去左上角「🔌 能力接入 → 音乐」接入 ACE-Step (或用 MiniMax 等), 同时先给出歌词文本; 用户只要垫乐时再退回 bgm-music。
- 任务丢失: 服务端偶尔丢任务且仍回"生成中", 脚本超过时长×3 会自动重提一次, 再失败会报错 —— 别自己写轮询脚本死等。
- 连不上 / 超时 → `$SG status` 看服务; gpu-a 服务冷启动第一首约 1 分钟, 再试一次; 还不行如实报告, 别拿纯音乐顶替。
- 给视频配歌: 生成后在 video-studio 的 timeline 里当 bgm 用 (人声歌建议音量 0.6~0.8, 旁白段落自动压低)。
